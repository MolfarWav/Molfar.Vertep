# 🎭 Molfar Vertep 0.9.5

What 0.9.2 left open. You can now see in the chat which parameters a reply is really sent with, linked chats remember further back, and Roleplay's settings stop arguing with the shell's. With Roleplay 4.30.0.

## ✨ What's new

### 🎛️ What a reply is sent with (Roleplay 4.30.0)
Open the switch in a chat's header and go to **Model**: under the model's name you see its **temperature**, **max output**, **reasoning** and **thinking budget**, each marked:
- **model**: set on the model in Settings › Connections and models;
- **preset**: from the chat's preset (the model leaves it unset, or the preset's "override the model" switch is on);
- **provider**: not sent at all, the provider's default applies.

### 📚 Backstory along a chain of chats
A chat that continues an earlier one got only that chat's story. Now A → B → C gives C the stories of B and A (up to three chats back). The Backstory budget stays one: the nearest chat gets the largest share, the oldest story comes first, and a fact is not repeated.

### ⚙️ Roleplay's settings next to the shell's
- **Context size** in a preset applied only to models whose window is unknown, yet it looked editable. When the model's window is known, the preset now shows that number marked **model**, with **Set up the model**. The same for **Max response tokens** while the model's Chat block sets it.
- **Language**: Roleplay starts in the shell's language (Ukrainian or English) until you pick one in Roleplay's own settings.
- **Matching by meaning**: the embeddings model is set in the shell (**Set up in Settings › Memory**), shared by every app.
- **Data**: the buttons say **Roleplay data**, and a link opens the shell's **Settings › Backup** for the whole profile. "Reset All Data" is now **Reset look and local settings**, which is what it does.

### 💡 Model recommendations with names
The recommended values for each block in a model's settings name example models (DeepSeek, GLM, Kimi, Gemini Flash) next to the kind of model they describe.

## 🛠️ Fixes
- Molfar's page: a finished run no longer shows **2 / 2** under your message, as if you had edited it.
- Roleplay: the chat list could hold a new chat twice for a moment (a warning in the console, a doubled row).
- Roleplay Home: the stat tiles no longer cut or break "Повідомлення" in the narrow column.

## Other changes
- `GET /v1/models/params/effective` answers the merged values with the source of each, given what the request would carry.
- Apps can read the shell's language and open Settings on the Connections, Models, Memory or Backup tab (trusted apps only).

## ⬇️ How to get it
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v0.9.5". Then open **Updates** in the top bar for Roleplay 4.30.0.
- **Running from source otherwise:** pull the tag `v0.9.5`.
- **Downloads** below: `Molfar-Vertep-0.9.5-<system>` for desktops and `Molfar-Vertep-0.9.5-android-arm64.apk` for Android 9 and newer (installs over 0.9.1 and later and keeps your data).
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.9.5` or `:latest`.
