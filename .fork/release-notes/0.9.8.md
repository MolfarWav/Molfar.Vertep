# 🎭 Molfar Vertep 0.9.8

A character card you can see at a glance. Roleplay splits a card into fields you can switch on and off. The model can fill the fields from the card's text or read the appearance from the portrait. Your persona gets the same form. Settings gains one place to choose the model that reads pictures. Molfar's page is redesigned and Molfar learns new tools. With Roleplay 4.33.0.

## ✨ What's new

### 🗂️ The card in fields (Roleplay 4.33.0)
The character editor has a new **Profile** tab, modeled on Lorebary's sheet. Its sections are Identity, Appearance, Personality, Behaviors, Goals, Background, Circles, Trauma, Relationships, Sexuality (adult characters only) and Notes. Together they hold birthday, weight, bust-waist-hips measurements, pet peeves, core beliefs, hobbies, career goals, origin, affiliations and more.
- The fields write **Description** and **Personality** as labeled lines. Text you wrote before stays as notes. If you edit the description by hand, the tab notices. **Free write** lets you keep your own text.
- **A switch on every section.** An off section keeps its fields but writes nothing into the card. A small context window then pays only for the sections that are on. Trauma, Circles and Sexuality start off until you fill them.
- **Easy to find your way.** Each section has its own icon and color. A side list with check marks jumps between sections; on phones it is a row of chips. Lists are chips you add with Enter. A male character is not offered measurements.
- The editor's tabs have icons and are grouped: text, world, look, tech.

### 🪄 Let the model fill it (Roleplay 4.33.0)
- **Structure it** reads the card's text and sorts it into the fields. It shows what Description and Personality would become.
- **Fill empty** proposes values only for empty fields, for one section or the whole profile. It never invents relationships.
- **Read from picture** is in the Appearance header. It reads the face, eyes, hair, build and the rest from the portrait, or from a picture you attach for this one request. Tick "Rewrite fields that are already filled" to replace what the text said.

Each one arrives as a draft. Nothing changes until you press **Accept**, and the old text goes to **Versions**.

### 👤 Your persona, the same way (Roleplay 4.33.0)
A persona gets the same Profile form under its Description. **Structure it** sits next to **Five questions**: paste a full persona text into the description, press it, and it is sorted into the fields. A long description folds away.

### 👁️ One vision model for every app
**Settings → Connections and models** has a new **Vision model** field. Apps send pictures to this model. Roleplay uses it to read a portrait.
- **Auto** picks the cheapest of your shown models that reads pictures, by the provider's catalog price.
- You can also pick one yourself. Roleplay can still override it for itself.

Models that read pictures include Gemini, GPT-4o and GPT-4.1, Qwen-VL, Pixtral and Llama 3.2 Vision. A model that cannot read pictures now refuses the request with a clear error. Before, it got a placeholder and guessed.

### 🧙 Molfar's page, redesigned
- **More room for the chat.** The sidebar folds to an icon rail. The header holds the model chip, a context meter (amber at 75 %, red at 90 %), the connection dot, the inspector, search and memory.
- **The project beside the chat.** It opens as a pane you can resize and fold. The pane shows instructions, memory, skills, checkpoints, files and the default model. Expand it to a full-width page with tabs. On phones a **Chat | Project** switch sits at the top, and a strip shows model, reasoning, context and cost.
- **Templates.** `/card`, `/lorebook`, `/preset`, `/fix` and `/skill` are in the "/" menu and show as starter cards in an empty chat. Each loads its skill and asks 2-3 questions first. A template is offered only when its skill is installed.
- **Under a reply:**
  - **Shorter**, **Simpler** and **Apply** buttons;
  - chips for the skills Molfar loaded, with their tokens;
  - chips for the memory notes it looked up, each opening the note;
  - a line with steps, tokens and cost.

### 🧰 Molfar plans big jobs and has new tools
- **Run budget.** Before a big task, Molfar shows the step count, tokens, cost and the files it will change. You answer **Go on**, **Smaller** or **Stop**. Writes to an app's code, or to a fourth file, wait for that answer. This is off in Accept and Plan modes.
- **New tools:**
  - `plugin_log` reads what an app's plugins logged, including failed routes and hooks;
  - `app_request` calls an app's own route to test what Molfar just built;
  - `model_try` makes one test generation after showing you the price ceiling;
  - `web_fetch` reads a public web page, only when the sandbox's internet switch is on.

## 🛠️ Fixes
- Android: when Play Protect stops the in-app update, the app offers the download in the browser. Before, the update closed silently. This helps from the next update after 0.9.8.

## Other changes
- Plugin llm requests can carry up to 4 pictures. A request with no `model` goes to the vision model; `GET /v1/models/vision` tells an app which one that is.
- Roleplay's Export offers PNG, CHARX (portrait, emotion images and gallery as files) and JSON. Exported cards no longer carry the version history; the full backup still does.
- Roleplay presets: "Use in this chat" and "Make default" are two separate actions.

## ⬇️ How to get it
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v0.9.8". Then open **Updates** in the top bar for Roleplay 4.33.0.
- **Running from source otherwise:** pull the tag `v0.9.8`.
- **Downloads** below:
  - `Molfar-Vertep-0.9.8-<system>` for desktops;
  - `Molfar-Vertep-0.9.8-android-arm64.apk` for Android 9 and newer. It installs over 0.9.1 and later and keeps your data.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.9.8` or `:latest`.
