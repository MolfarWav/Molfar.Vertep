# 🧾 Molfar Vertep 1.3.0

A chat can continue another one and carry its world with it, a character gets a long memory and skills it earns in play, and custom connections to reasoning models work again (Chub). Almost all of it is Roleplay 4.61.0, which comes as an app update; the engine changes in one place (below).

### 🔗 A chat that continues another carries its Dashboard (#100)
Link a new chat to an earlier one (Canvas wire or Chats map) and its Dashboard starts from where the earlier one ended: open threads, the characters' numbers, mood, place, names, the live notes and what was said. A banner says what came over, with **Start clean** (turns off the Dashboard and the Litopys backstory of that link together) and **Carry it over again**. A chat linked late, after its own Dashboard had read turns, can **Rebuild on top**; the old state is kept in a copy.

### 🧠 A character's long memory (#102)
Characters → a card → **Memory** tab. Before you delete a chat, add it to the card's memory: a short summary, the strongest facts, notes and said lines, chosen in a preview. New chats of the card start knowing them. Nothing repeats what Litopys, the Dashboard or the card already say, a deleted chat breaks nothing, the text does not change between replies (so the provider's prompt cache holds), and one chat can leave a story out.

### 🎓 Skills (#106)
A skill is a short rule for how a character acts ("answers threats with silence"), not an ability. You write them in the Memory tab, Molfar can propose them, and they act in every chat of the card. They are also **earned in play**: when Litopys closes a scene it may notice a habit a character shows; seen once it is a candidate, seen in a second scene it is earned and starts to act in that chat at once. The Library's chat record has a **Skills** tab (evidence, switch, edit, reject, **Keep on the card**) and a toast says when one is earned. Most scenes give nothing.

### 🗣️ What was said (#98)
The sensor keeps a separate list of what characters said and are held to (vows, threats, secrets, lies). After testing it is stricter: a greeting, an introduction or an ordinary request is never kept, each item has a strength and only 2 and 3 count, one a turn by default, and what the Notebook already holds is skipped.

### 🧭 What a chat carries (#107)
A strip under the chat header shows what goes into the prompt besides the history (the card's memory and skills, the Litopys backstory and record, the Dashboard, what was said, the World DM, the Author's note) with tokens, a panel with a switch per part for this chat, and the exact lines.

### 🔧 Smaller
- The memory parts now say what they are for: the characters remember it, a question about it gets a real answer, and an opening that reads like a first meeting is a later scene of the same story (#110).
- **Rebuild from scratch** no longer empties a chat that has no closed scene (it refuses to start, and a rebuild that wrote nothing is dropped).
- Chub and other strict servers (#59, engine): a custom connection to a model marked as reasoning sent the system prompt with the role `developer`, which only OpenAI knows; it now sends `system`. The reporter confirmed the cause. NanoGPT and other OpenAI-compatible connections send `system` too.

## How to get it
Roleplay 4.61.0 comes as an app update (Apps → Updates); the engine part is in this release (restart after updating). From source: `Molfar-Vertep.bat` picks up the new release. Downloads: the archives and the Android APK on this release page. Full list: [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
