# 🖌️ Molfar Vertep 1.2.1

Molfar can draw: ask for an avatar, a background or a gallery picture and it lands in the card. Settings → Images gets your own short list of image models, so a cheap or local model can do backgrounds and a better one the characters. Roleplay 4.50.0 writes Danbooru tags for tag-trained checkpoints on ComfyUI and Forge.

### 🖌️ Molfar draws pictures
Until now Molfar could not make a picture: asked to "set an avatar for Jude", it had no way to draw (#54). Now it has its own drawing tool, using the same image models as your apps. Ask in plain words, for example "make an avatar for Jude" or "draw a rainy street as a background". Molfar reads the card, writes the picture prompt, draws it and puts it where it belongs: the character's portrait, their gallery, or your list of chat backgrounds. The picture shows up in Molfar's chat too.
- **Paid models ask first.** Before each picture on a paid model (OpenRouter, NanoGPT, an online server) Molfar shows a card with the model and the prompt: **Draw** or **Skip**. A ComfyUI or Forge on your own machine draws without asking, since it costs nothing.
- Molfar picks the model by what you said each one is for (next section). Without a list it takes your local server first, otherwise the first model.

### ⭐ Your image models (Settings → Images)
Choosing among hundreds of image models every time is no fun. **Settings → Images → Your image models** is a short list of your own: star models in the searchable **Models** list under each connection or server, give each a name and say what it is for ("backgrounds, cheap", "characters"). Reorder with the arrows: the first is the default for anything that names no model.
- Molfar sees only this list with your notes and picks the model that fits the picture.
- Roleplay (4.50.0) shows these models first in its own picker, starred and with your names; its choice stays in Tools → Image Generation.

### 🏷️ Danbooru tags for ComfyUI and Forge (Roleplay 4.50.0)
Tag-trained SDXL checkpoints (Illustrious, Pony and the like) draw badly from a paragraph of prose (#53). **Tools → Image Generation → Prompt style** now offers **Description** or **Danbooru tags**. **Auto**, the default, picks tags for models that run on ComfyUI or Forge and a description for everything else, and says which one it is using. With tags, `/imagine` and the character's Picture tool write a line like `1girl, solo, silver hair, green eyes, leather jacket, night, rain, upper body`. Put quality tags (masterpiece, best quality…) in the common prefix; the negative prompt keeps working as before.

## Other changes
- The image settings in Roleplay name NanoGPT and image servers when no image model is found (they used to mention only OpenRouter).
- Molfar's card skill (`edit-large-card`) knows where a picture goes: `avatar`, `studio.gallery`, or `backgrounds` in the app's library.
- Engine: `GET /v1/images/models` also returns `favorites`; `PUT /v1/images/favorites` (Settings only, apps cannot call it) saves the list in `images.json`.

## ⬇️ How to get it
- **The Roleplay changes come with the app 4.50.0:** update Roleplay (the launcher, or the app's update button). The prompt style works on any engine; your image models first in its picker need Molfar Vertep 1.2.1.
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v1.2.1".
- **Running from source otherwise:** pull the tag `v1.2.1`.
- **Downloads** below:
  - `Molfar-Vertep-1.2.1-<system>` for desktops;
  - `Molfar-Vertep-1.2.1-android-arm64.apk` for Android 9 and newer. It installs over 0.9.1 and later and keeps your data.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v1.2.1` or `:latest`.
