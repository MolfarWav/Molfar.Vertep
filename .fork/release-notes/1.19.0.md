# 🗺️ Molfar Vertep 1.19.0

An engine release that brings the pictures for Roleplay's new **places map**, and two app fixes. **Order:** get this engine release and restart first, then press Update for Roleplay 4.140.0 (Updates dialog). The new Roleplay works without this engine, but then it shows emoji and the dotted grid instead of the painted icons and plans.

## 🗺️ Painted place icons and ready map plans
The engine now carries the art for the map of a chat's places (Roleplay):
- **90 kinds of place icon**, three to eight pictures each: a fantasy town (tavern, forge, castle, temple, cave, forest, ship...) and a modern city (hospital, police station, cafe, restaurant, skyscraper, metro entrance, gas station, post office, cinema, karaoke bar, arcade, airport...). Every icon is a small WebP with a transparent background.
- **72 ready map plans** in two packs, a fantasy one (a region, the wilds, a coast, a walled town, a village, a harbour town, a house plan, caves) and a modern-city one (downtown, suburb, industrial district, campus, waterfront, old town, airport, metropolis, city park, small town), four of each kind, with thumbnails.
- Roleplay picks an icon from a place's name, shows a ready plan that suits the places when you have chosen nothing, and offers a gallery of the plans. Both read the files from the engine: `GET /v1/place-icons`, `/v1/place-icons/<kind>-<n>.webp`, `GET /v1/map-packs`, `/v1/map-packs/<pack>/<map id>[-thumb].webp`. They are read-only, need a signed-in user, and an app frame may read them and nothing else under those paths.
- The files add about 20 MB to a download. More sets (more kinds, dungeon plans, a world map) will arrive the same way.

## 🖼️ Other changes in this release
- **A picture in an SVG `<image>` loads inside an app (#460).** The frame swapped an engine address for a `blob:` URL only for `src`, `poster`, `srcset` and `style`, so an SVG `<image href>` stayed broken; it is covered now.
- **An app reads another app's file in pieces (#467).** `host.peer.read(app, path, { offset, maxBytes })` returns one piece of a large file, so an app with read access can open a very long chat.

## 📦 What arrives through app updates
- **Roleplay 4.140.0:** the places map (a floating map over the chat: places as painted icons on a ready plan, roads the story walked or you draw, travel by a tap with minutes from the distance, an optional road event, rename on the map, pick an icon by hand, a lock for phones), plus two fixes: a character who keeps pressing the player for "one true thing" no longer becomes an open thread, and importing one persona from another app is one persona (a persona can have a book of its own that travels with it).

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
