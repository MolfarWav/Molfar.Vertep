# 🧭 Molfar Vertep 1.0.10

Molfar Vertep now explains itself. The shell, Molfar's page and Roleplay 4.47.0 get a help list you can search, with **Show me** that takes you to the right place, and short tours the first time you open a screen. The Windows launcher stops on a folder Git refuses instead of carrying on, and installing an app survives a folder Windows still holds.

### ❓ Help, everywhere
**Help** is in the account menu (top right) and at the bottom of the start page. It lists what Molfar Vertep can do: connecting a model, apps and the Store, Split, updates, backups, Molfar, reporting a bug. Search in English or Ukrainian. **Show me** opens the place and points at the button. Molfar's page has its own **Help** (in the header; on a phone in the sidebar), and Roleplay 4.47.0 has **?** in its left rail.

### 🧭 Short tours on first visits
The first time you open the start page, an app, Settings or the Store, a tour of two to four steps shows what is there. A fresh install starts with how to connect a model. Molfar's page gets tours for a chat (the message box, modes, memory) and for a project page (instructions, checkpoints, files). Roleplay 4.47.0 adds tours for the chat menu, the Dashboard, Soul, the Library, Characters, Groups, Lorebooks and Presets. Skip any tour; turn tours off or play them again in **Settings → General → Guide**. Tours remember what you have seen on every computer you sign in from.

### ✨ What's new after an update
After an update, a small card points out what is new since your last version, one item at a time, with **Show me**. This time: **Ask Molfar first** in Report a bug, and the help list itself.

### 🛡️ Clear about what Molfar may do
The help on Molfar's page says exactly when he asks first: before he changes a protected file (an app's code), with **Allow** or **Don't allow** for that request; before every shell command in **Accept** mode; with a plan card before a big change in **Full** mode. It also explains **Undo** after a run and saving or restoring checkpoints.

## 🛠️ Fixes
- **Windows launcher, a folder Git does not trust** (#33). When Git refused the Molfar Vertep folder ("dubious ownership": a second drive, a USB stick, a folder made as administrator), the launcher took it for being offline and went on to install Bun anyway. It now stops, explains why, and offers to trust that one folder; if you say no, it shows the command to run yourself. Any other Git error stops it too. The README says what to do.
- **Installing an app on Windows** (#34). Installing Roleplay could fail with "EPERM: operation not permitted" when the copy left by an earlier attempt was still held by something (an antivirus scan, File Explorer). The engine now tries again, then moves the old copy aside, and only if both fail tells you which folder to close or delete.

## Other changes
- The guide's state is the `guide` key of the user's settings (`GET`/`PUT /v1/settings`), checked on the server; saving it does not restart Molfar's chats.
- The built-in `app-authoring` skill tells Molfar to add a guide tip for a feature he builds in an app that has a guide; Roleplay's AGENTS.md describes the format.
- Tip texts are in English and Ukrainian; other shell languages show the English text.

## ⬇️ How to get it
- **The Roleplay changes come with the app 4.47.0:** open the launcher and update Roleplay. It works on any Molfar Vertep 1.0.0 and later.
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v1.0.10".
- **Running from source otherwise:** pull the tag `v1.0.10`.
- **Downloads** below:
  - `Molfar-Vertep-1.0.10-<system>` for desktops;
  - `Molfar-Vertep-1.0.10-android-arm64.apk` for Android 9 and newer. It installs over 0.9.1 and later and keeps your data.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v1.0.10` or `:latest`.
