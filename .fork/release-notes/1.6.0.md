# 🎲 Molfar Vertep 1.6.0

A way back for an app that will not start, and Roleplay 4.73.0 with the dice for the World DM. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

### 🛟 Restore Roleplay when it does not start
If the app shows "Can't reach the Molfar Vertep engine: plugin roleplay__engine route GET /bootstrap failed: invalid property name", one of its code files is broken. Usual causes: an update that left merge conflict markers (`<<<<<<<`) for the built-in agent and nobody resolved them, or a file the agent edited and broke.

Close the app and run `Molfar-Vertep.bat`, then press **8**. It lists the broken files and what would change, asks, and writes the version Roleplay shipped in over its code. Your chats, characters and settings (the `data` folder) are not touched; the replaced files stay in the workspace history. The same from a terminal: `chrysalis restore-app roleplay` shows the plan, `--yes` applies it. With more than one account add `--user <name>`.

### 🎲 Roleplay 4.73.0: dice for the World DM
Off by default. In a chat's World sheet (Living world and up) a Dice card has a three-way switch, Off, Hint or Binding, with the explanation of the chosen position shown under it. Before a reply is written, code rolls 2d6 and tells the model how an uncertain action turns out: miss, no but, yes but, or full success.
- **Stat by the action.** One roll for the scene; each present character's Dashboard numbers give their own result, and the model takes the person you act toward and the stat that fits. Or fix one stat for the speaker. Someone with no numbers gets the bare dice.
- **How luck runs:** kind, even or harsh moves the limits between the four outcomes. **Replies with a roll** sets how often.
- **A result you already wrote** stays; the roll then sets how the others react and what it gains or costs.
- **World intervenes** (off by default): its own roll, apart from the action's. When it hits, a d6 sets the size (a small thing, a real interruption, a large turn).
- **Seen, not hidden:** the prompt Inspector shows the line as "Dice" or "Life"; the card folds away the last ten rolls; and a switch, Show under the reply, adds a small mark under each reply that had a roll.
- A new **Agents** segment sits in the chat's quick-switch bar, so the agents are in view at once.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
