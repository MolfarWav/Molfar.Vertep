# 🏠 Molfar Vertep 1.15.0

Molfar's mailbox grows up, and Roleplay stops hiding a broken letters model. **Order:** get this engine release and restart, then press Update on **Roleplay** (4.109.0) in Updates.

## 📬 Molfar's mailbox takes skills
- A card that proposes a skill (a new one, or a fix to one you have) now has **Later** beside Save and Skip, like a memory card. Later, a card nobody answered and a run with nobody to ask leave the whole skill in the **Mailbox** tab of Memory and skills (the brain button on Molfar's page).
- A new skill is shown whole; a change to a skill you already have is shown as a diff. Nothing is saved until you press its button. A Skip is remembered, so the same skill does not come back; a revised version is a new proposal.
- A chat that finished while you were in another chat waits in the Mailbox too, with **Open** and **Dismiss**, and counts in the number on the brain button.
- That number no longer lags: it updates right after a run ends, a card is answered or a background chat finishes, not only every 30 seconds.
- The Molfar guide page, a Help tip and a What's new tip describe it.

## ✉️ Roleplay 4.109.0: a broken letters model says so
Letters from cards are written in the background, so a model that kept failing (an expired key, no model set, an empty reply) just meant no letters. After three checks in a row that failed on the model, the Inbox shows a red **Letters** failure with the reason; Open takes you to Characters, More, Letters from cards, where the dialog repeats it. A letter that arrives, a different writing model or switching letters off clears it. One or two bad checks stay quiet.

## Known limits
- Tried with a fake model only: a real model's skill suggestions and letters, a phone, and a chat finishing live in the background were not checked.
- The finished-chats rows repeat the marks the chat list already shows; the mailbox just keeps them in one place with the number.
- The new guide strings are translated by a cheap model without a native read.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Apps: Updates > Roleplay > Update. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
