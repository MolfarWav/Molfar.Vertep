# 🧬 Molfar Vertep 1.9.1

A small release: one fix in Sync, a newer Bun inside the builds so the Edge voice can recover from a wrong PC clock, and Roleplay 4.80.2 as an app update. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## 🔄 Sync
- When a pull has files that changed on both devices, you choose which version to keep and press "Pull with these choices". That pull now shows its progress ("Downloading 120 of 4000...") with the bar, like a plain Pull does; before, the screen showed nothing moving until it finished.

## 🔊 Edge voice and a wrong clock
- The release builds and the tests now use Bun 1.4.4 (was 1.4.0). Under 1.4.0 the Edge voice could not read the server's time from a refused connection, so a PC whose clock was off by more than a few minutes got no voice and a bare "403". With 1.4.4 it corrects the clock and retries once. This is not tested on a release build against a real skewed clock yet.

## 🏠 Roleplay 4.80.2 (app update)
- **Open in Marketplace** opens the page of the card Home shows, not only the list.
- **From your library** was blank for every card; it shows the description (or the chat's last words), when you last played, and coloured chips for chats, lorebooks and tags.
- **Waiting on you** shows what waits by kind (failures, approvals, soul reviews) and the first three rows; each one opens what it names.
- **Pick up the story** shows the character's portrait in a frame at its own size; before, a small picture was stretched over the block. A card with no picture of its own shows none.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
