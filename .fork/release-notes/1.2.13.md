# 🧾 Molfar Vertep 1.2.13

Cost checks per connection, a few phone fixes in the shell, and Roleplay 4.59.1 to 4.59.3 as app updates: the inbox opens at the first click, background tools, translations you can cancel, and a Dashboard that says when it throws facts away.

### 💳 Cost checks per connection
Molfar's questions about money (the estimate before a big task, the confirmation before a paid test generation or a paid picture) had one global switch (Settings → Molfar → Cost checks). Now each connection can have its own (#91).
- In **Settings → Connections and models**, the Add and Edit forms of a connection have a **Cost checks** choice: *Follow the global setting* (the default), *Ask before spending (on)* or *Never ask (off)*. It covers that connection's models only.
- With the checks off for a model, **its price is not shown** on the agent page either: the phone header line, the run summaries and the Inspector keep the token counts and drop the dollar figure. Prices stay in the data. This also applies when the global switch says "Never ask" or the model runs on your own machine.
- `MOLFAR_VERTEP_COST_CHECKS=off` still switches the checks off for the whole instance and wins over a connection's setting.

### 📱 Small phone fixes in the shell
- The size line on an app's page ("3 files · ~4 KB") is translated.
- The launcher footer in Ukrainian wraps in whole items at 390 px instead of cutting words.
- The icon-only buttons in Settings → Images (such as delete) are 40 px on a phone.

### 📥 Roleplay 4.59.1 to 4.59.3 (app update)
These come through **Apps → Updates**; the engine does not need to change for them.
- **Inbox opens at the first click.** With a card editor or another section open, the rail button closed that section and the inbox shut itself in the same moment, so the click seemed to do nothing.
- **"Change the background by scene" is back** on the chat's Backgrounds tab (World → Chats → a chat → Backgrounds), above the folder.
- **Places you type** in "Make a set" now show up as a ticked chip; before they were counted in the cost line but not drawn.
- **Add from existing** in a world's Backgrounds: copy pictures from other folders (other worlds' chats, the general library) into this one, with search and several at once.
- **Search in Tools → Backgrounds** over all pictures by name, tag or folder name.
- **Cancel for translations.** A long card, field or lorebook translation has a Cancel button; nothing is written when you cancel.
- **The Prompt board on a phone** shows the token total once.
- **The Dashboard says when it throws facts away** (#97). The sensor sometimes wrote "what a character saw, heard or guessed" with your own character as the holder, which the notebook cannot keep, and nothing said so: the notebook stayed empty. The sensor prompt now says whose facts they are, and the Dashboard shows a line when it had to drop some. With debug on, the last ten sensor replies are kept in `_debug/dashboard-runs.json`.
