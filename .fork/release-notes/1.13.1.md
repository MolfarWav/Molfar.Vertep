# 🏠 Molfar Vertep 1.13.1

A small engine release for the **Social** app: an app can now send you to Home. Social uses it in the dialog that says Roleplay access is off, so one button takes you to the setting instead of a text hint. Roleplay is unchanged. **Order:** get this engine release and restart, then Update Social in Updates.

## 🏠 Apps can send you Home
- An official app calls `window.molfarShell.openHome()` and the shell switches to Home, where each app's details and **Access to other apps** are.
- Only the app on screen is heard. An app that is not official gets nothing. An engine older than this has no `openHome`, so the app keeps its text hint (Social checks for it before drawing the button).
- The `app-authoring` skill has a short section on it, so Molfar knows the call when he builds apps.

## Social (ships by Update, not with this release)
- Forum: search across topics (Home and a button in a topic), pages of 25 posts, the Back button of the browser and the phone steps through search, topics and pages.
- Forum moderation: you can remove a post (a short note stays in its place) or delete a whole topic, and close or reopen a topic. Characters cannot.
- The "Open Home" button in the Roleplay import dialog and in Settings.

## Known limits
- The forum prompts were not tried with a real model yet; the Roleplay import was tried with a mock model only.
- The Back button was checked in a desktop browser and a phone-sized window, not in the Android app's WebView.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
