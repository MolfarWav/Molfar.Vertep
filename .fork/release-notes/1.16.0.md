# 🏠 Molfar Vertep 1.16.0

A safer write for plugins, and Roleplay learns a few things about lorebook keys and the prompt budget. **Order:** get this engine release and restart, then press Update on **Roleplay** (4.110.0) in Updates.

## 🛡️ A chat can no longer be read half written
A plugin's file write used to empty the file first and fill it after, so a read that landed in between (Roleplay loading a chat while the Dashboard, Litopys, World DM or an agent was saving it) could see an empty or cut-off transcript. Files are now written to a temp file and swapped in, so a reader gets the old file or the new one. The same goes for a plugin's settings. On Windows, if another program keeps the file open and the swap is refused, it is retried for a moment and then written the old way, so nothing is lost.

## 🔑 Roleplay 4.110.0
- **A name in a lorebook key finds the same name in the other alphabet.** The key *Kael* fires on «Каел» and «Каелу» in the chat, and the key «Каел» on *Kael*. Only names (a key word of four or more letters written with a capital, against a capitalised word of the chat), whole words, and the same sound: «Кейл» is not *Kael*, and a lowercase key such as *power* never crosses. It follows the book's **Word forms** switch, which is on by default, so there is nothing to turn on. Checked on 43 real books against real chats: 90 extra fires, all names.
- **The prompt budget asks each memory plugin.** Dashboard, Litopys, World DM and the agents now say themselves how much they may add to a request, and the history is trimmed for that. A group's Dashboard reserves three characters, not two. It costs about 0.3 s more per send on a desktop, more on a phone.
- **The recollection editor** no longer shows a limit of 300 for a moment before the real setting arrives.

## Known limits
- Not tried: a send with the new budget on a real model, a phone, the editor after the fix.
- A key in lowercase letters never crosses alphabets; translate the book for that.
- Quotes that name nobody in a Narrator card stay in the base colour when the card's Voices list does not name the speaker; a per-card default is proposed in issue 365.
- The new guide strings are translated by a cheap model without a native read.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Apps: Updates > Roleplay > Update. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
