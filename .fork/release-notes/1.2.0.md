# 🎨 Molfar Vertep 1.2.0

Pictures from more places: NanoGPT and your own image servers (ComfyUI, AUTOMATIC1111/Forge, any OpenAI-compatible one) join OpenRouter. Roleplay 4.49.0 opens fast with thousands of characters, tells you when the Library waits on you, and keeps resolved Dashboard threads closed.

### 🎨 Image generation: NanoGPT and your own servers
Pictures in apps (Roleplay's image generation among them) used to come only from OpenRouter. Now:
- **NanoGPT**: works with the NanoGPT key you already connected. Its image models show up with their price.
- **Your own image server**, set up in the new **Settings → Images** tab: a **ComfyUI** on this computer or your network (a ready text-to-image workflow, or paste your own API-format workflow with `%prompt%`, `%negative_prompt%`, `%model%` and the like), **AUTOMATIC1111 / Forge**, or **any server with an OpenAI-compatible** `/images/generations`.

Their models appear in the app's model list next to the others, with the server's name. What Roleplay asks the picture to avoid becomes a real negative prompt on ComfyUI and Forge. A key you save for a server stays bound to that server's address. If something goes wrong (wrong key, no credit, server off, too slow), the app says so in plain words.

To change a saved server for now, delete it and add it again.

### 📚 Thousands of characters (Roleplay 4.49.0)
With about 700 characters Roleplay stopped opening: at start it loaded every card whole (#46). Now it starts from a short list: name, portrait, tags, the start of the description and a token count. A card loads in full when you open it, chat with it or export it. With 2,000 characters the app opens in about 2 seconds. The first start after the update builds that list in the background (about half a minute for 2,000 cards), and the Characters page fills in meanwhile.
- Portraits come as the list shows them, with a soft placeholder until then.
- Search on the Characters page covers names, tags and the first 1,000 characters of a description. Token counts on tiles are marked `~` until the card is opened.
- Importing many cards at once now goes in batches of 25. A few hundred in one go used to stop halfway with an error.

Moving a whole SillyTavern library over (characters, personas, chats, groups in one go) is the next step; this release is the ground it needs.

### 🔔 The Library tells you when it waits on you (Roleplay 4.49.0)
When the Library suggests pinning, merging, rewriting or retiring a fact (#55), you now see it: a count on the Library icon (on a phone, in **More**) and on that chat in the Chats list, plus a short notice. With one suggestion you can accept or reject it right in the notice. With several, **Open** takes you to that chat's Overview. The notice never takes the keyboard and waits while you type. **Library settings → Tell me about suggestions** turns it off; the Soul tab has the same switch for proposed souls.

## 🛠️ Fixes
- **A thread you closed came back** (#47, Roleplay 4.49.0). A Dashboard thread you added came back open one turn after the sensor resolved it. Resolved threads now stay resolved and stay in the list as history (the newest 20, with the turn they closed on).
