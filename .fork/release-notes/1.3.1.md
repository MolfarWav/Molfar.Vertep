# 🧾 Molfar Vertep 1.3.1

Narrator cards with several characters work, the Dashboard has colour, and every import shows its progress. All of it is Roleplay 4.62.0, which comes as an app update; the engine itself has no code change in this release.

### 🎭 A card with several characters (#115)
Open a narrator card → **Profile** → **Structure it**. It now finds every named character in the Description (blocks like `[Name …]`), files the first as the profile and the others as the cast, and shows how many it found before anything changes. A long card read in parts keeps one profile per character across the parts. **Fill empty** now works on every character, not only the first: type the character's first name in Identity and it finds them in the text by that name. If the model's window is not known, the card is read in parts of about 6k tokens: raise **Card text per call** in the card's task panel if your model takes more (the panel now says so).

### 🎨 Dashboard colours
Each block sits on a tinted title bar with an icon: blue for the scene, violet for people, green for memory, pink for plot. Marks carry their meaning: an event's weight (pivotal is red, significant amber), what kind it is, how a note is known (saw, heard, guess), what was said (threat red, vow green) and a character's class. The tints sit over your theme's own colours.

### 📊 Import progress (#116)
Importing characters, presets, lorebooks, personas, regex scripts, chats, a backup or a card from a link now shows a card at the bottom: the file, the step, "3 of 12", a bar, and **Cancel**, which stops before the next file (what is imported stays). At the end it says "Imported 30 of 31" and lists the files that failed. One big file shows its steps instead of a made-up percent; a card downloaded from a link moves with the bytes it has read.

### Known
The card Memory tab's import dialog and the percent inside a single big preset or chat are not covered by the progress card yet (#116).
