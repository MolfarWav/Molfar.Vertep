# 🧠 Molfar Vertep 1.11.2

Long chats with big embedding models no longer stall, characters can write to you (and you can find the switch), cards get portraits drawn for them, places get drawn while you play, and Botbooru joins the Marketplace. The engine itself is unchanged; everything arrives as **Roleplay 4.93.0, an app update**. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## ✉️ Letters from cards are easy to find
- A card you have not played for a while can write you a short note in its own voice. It was there since 1.9.2 but off by default and three clicks deep, so it went unnoticed. Now, while it is off, a green card **"Let your characters write to you"** sits at the top of Characters and in Home's "Waiting on you". **Turn on** switches it on in one tap (the settings open if no background model is set up); **Not now** hides the card for good. The switch and the limits stay in Characters, More, Letters from cards.

## 🎨 Portraits for cards that have none
- In the card editor, **Draw** under the portrait opens a dialog. Pick the image model, a text model writes a description of the card (you can edit it), the image model draws it. The picture goes to the card's Gallery at once; **Use as portrait** makes it the avatar.
- **Characters, More, Draw missing portraits (N)** does it for every card with no picture of its own: pick the model, and the cards are drawn one after another through the progress card. Cancel stops it between cards, and a card that fails is listed with the reason (a card with only a name has nothing to describe).
- **You choose where it is drawn.** "Draw with" lists the image models of Settings > Images: a local ComfyUI or Forge next to API models. The first choice is the app's own image model (Extensions > Image generation); your pick here is remembered for portraits only. A tag-trained model gets a line of tags, an API model a paragraph. Image generation must be on; the dialogs tell you and open it.

## 🌄 Places drawn on the spot
- World > Backgrounds has a new switch under "Change the background by scene": **Draw places that have no picture**. With it on, when the story reaches a place your folder has no picture of, the Dashboard names it, the World's image model draws it (from the World's own record of the place when there is one), files it in the folder and uses it. One drawing at a time, at most one a minute per chat, and a place that failed is not retried for 15 minutes. Each picture is a model call. The chat's Display sheet has a link to it.

## 🔎 Botbooru in the Marketplace
- A new source: search, sort, preview and import by link (`botbooru.com/character/<id>`). It shows safe-for-work cards only, since the app has no account there.

## 🛠️ Fixes
- **Long chats stopped writing chapters with big embedding models** (reported on Discord, 3072-number models such as `text-embedding-3-large`). The chat's vectors lived in one file that grew past the 4 MB limit for plugin writes, the failed save stopped the whole tick, and the same embedding batch was asked for again and again. Vectors now go on in extra files when one is not enough (an old big file is read and split on the next save), the Data Bank's vectors and the lorebook vector cache do the same, and a batch that cannot be saved ends its request and lets the chapters go on. After updating, press **Embed** on a chat that failed before.
- The lorebook vector cache no longer fails silently (it re-embedded a big book on every send); a failure goes to the log.
- The Permissions dialog switch shows its new state at once; the solid green buttons are readable in light themes; the chat's agent list shows "…" instead of ids until it has loaded; the Forge's widget kind select no longer clips its text.

## Known limits
- Tried in a browser with fake models only: not with a real image backend (ComfyUI, Forge or an API model), not with a real model naming places in the Dashboard, not with the real Botbooru site, not on Windows or a phone.
- Botbooru's own `robots.txt` asks crawlers to stay away from its post and image paths; the app makes one request per action of yours and fetches nothing ahead.
- The card editor is still English only (its new Draw button too); the new dialogs are translated.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
