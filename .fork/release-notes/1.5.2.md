# 🔧 Molfar Vertep 1.5.2

A patch release. The engine itself is unchanged; Roleplay 4.72.0 rides with it as an app update. **Update in this order:** get this engine release and restart, then open Updates and press Update on Roleplay. The built-in presets lose their context window on that update, and the preset refresh from 1.5.1 needs the engine first.

### 🪟 The context window is the model's alone
A preset used to carry its own context size, and that number could cut a long chat's history on a model with a much bigger window (a missing one meant 16384). Now a preset has no window at all. The number comes from the model: the catalog, the provider's model list, or the value you set in the model's own settings. When none is known, Roleplay assumes 32768 and says so under the chat, with a "Set it" button; you can close the note and it stays closed for that model. Presets you import (SillyTavern `openai_max_context`, Studio `max_context`) lose that number on the way in; a window already stored in an old preset file is ignored.

### 🧩 Agents: pace and size
- **How often an agent runs.** An installed agent's "Model, limits and pace" now has "Runs every N replies" (1 to 50). It overrides the author's cadence for you only and "Use the author's" puts it back. It is per installed agent, not per chat.
- **A bigger Input.** The Input card's history source gets "Most recent messages" (up to 60, 10 by default) and "Most tokens": the oldest rows are dropped until the text fits, the newest message always stays. This is a cap the author sets, not an automatic fit to the role model's window.
- **Try shows the size.** Each asked model's card says `~N tokens in`, so you see what the agent sends before it runs on a small model.

### 🔤 Fonts for replies (#126)
A reply, or your Custom CSS, can now name `Caveat`, `Marck Script`, `Lobster`, `Playfair Display`, `Cormorant Garamond`, `Oswald`, `PT Mono` or `Ruslan Display` in `font-family`. They ship with the app in Latin and Cyrillic and nothing is fetched from the net. A reply still cannot bring a font of its own. The fenced html block runs in a sealed frame that does not see the app's fonts, so they dress the reply's text, not what is inside that block. A self-sizing html block stays open in #126.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
