# 🧹 Molfar Vertep 1.2.11

Fewer questions about money when your model is local, a new app Molfar builds now shows up where you can open it, links to card pages work again, and a tidier inbox.

### 💸 Cost checks: ask, or don't
Molfar used to stop before a big task, a paid test generation or a paid picture to show an estimate and wait for your yes. With a model on your own machine that is noise (#77). There is a new switch in **Settings → Molfar → Cost checks**:
- **Auto** (the default): the questions are skipped when the model runs on your own computer or network (localhost, LAN addresses, container names such as `llama-swap` or `host.docker.internal`) and kept for hosted models, as before.
- **Always ask** and **Never ask** override that for everything. Never ask also drops the plan card Molfar shows before changing an app's code, and Molfar's prompt stops mentioning the estimate.
- For a whole server (a container, a machine with only local models) set `MOLFAR_VERTEP_COST_CHECKS=off` in the environment.

### 🧩 An app Molfar builds is an app you can open
Asked to build an app from scratch, a local model used to write files into a folder by hand, run them with node and give you a localhost address. Nothing listed such a folder, so you could not open it (#78). Now:
- a file written into `apps/<name>/` where that folder is not an app yet (no `manifest.json`) is refused with "call `app_create` first", and the app tools show up for the next step;
- Molfar's prompt, the small-model prompt and the app-authoring skill say that an app is made with `app_create` and opened from the app switcher (a new tab), never at a localhost address.

### 🔗 Card pages open from the app
A card's page on JannyAI ("Get on JannyAI") did not open from Roleplay: the browser said the network access was revoked (#58). The cause was the tab opened from the app's frame inheriting the frame's network allow-list, which names only the hosts the app's plugins use. Links to other sites (`target="_blank"`, Ctrl-click, `window.open`) now go through the shell, which opens them as ordinary tabs, after a click, never to an engine page. "Open on Chub" and the rest keep working.

### 🔑 Signing in to a subscription from another machine
When Molfar Vertep runs on a server and you sign in to Claude (or another subscription) in a browser on a different computer, the redirect goes to a local address that machine does not have, and there was nowhere to paste it (#80). The sign-in step now shows the link and a box: paste the redirect URL or the code, and the connection finishes. If the redirect does arrive, it still finishes by itself.

### ➡️ Corrections say when they are read
A correction sent while Molfar works shows "Molfar reads this after its current step. Stop ends the run now." under your message until the model has taken it in. And answering a question card that already timed out no longer ends in a red "no pending question": during a run your words go to Molfar as a correction (#73).

### 📥 A tidier inbox (Roleplay 4.58.0, an app update)
- Every inbox row has a **Dismiss** button, not only failures. A failure stays hidden until that job fails again, a Library row until it gets new proposals (the proposals stay in the Library), and a Soul review is dismissed, which deletes its proposal.
- **Select** turns on checkboxes: tick rows or press Select all, then Dismiss N at once. A batch that includes Soul reviews asks twice. The chips (Failures, Approvals, Souls, What's new) still filter by type.
- Soul reviews of cards you deleted no longer show up as a blank "..." row that opened the Characters list with nothing to open (#82).
- To get it: Apps → Updates.

## Other changes
- The engine log says which changed files made an open app rebuild (`build_needed: ...`) and whether a build was hot or a full one that reloads open pages. It is there to find why an app page sometimes reloads by itself.
- pi stays at 1.2.0: 1.3.0 is younger than the 7 days a new pi version waits.

## How to get it
From source: `Molfar-Vertep.bat` picks up the new release. Downloads: the archives and the Android APK on this release page. Roleplay 4.58.0 comes as an app update (Apps → Updates). Full list: [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
