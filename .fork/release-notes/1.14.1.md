# 🏠 Molfar Vertep 1.14.1

A small release: one engine fix for a crash, and a Roleplay update that makes closing scenes much easier. **Order:** get this engine release and restart, then press Update on **Roleplay** (4.107.0) in Updates.

## 🛠️ The engine no longer crashes when the local embeddings model wakes up
If you use the one-click local embeddings model (Settings > Memory), the engine could die with `NAPI FATAL ERROR` (Windows, after a few hours): the model is let go after ten idle minutes and was loaded again inside the same program, which its native part does not survive. The model now runs in a process of its own, so a failure costs only that one embedding and the next call starts a new process. Letting it go also frees its memory for real now.

## 🎬 Roleplay 4.107.0: closing scenes
- **Suggest scenes.** A chat whose characters never move had nothing for Litopys to close a scene on, so a long story could stay one open scene. The chat's record (Library, or the Record panel) now opens with a **Scenes** card: how many messages are in no scene yet, and **Suggest scenes**. The model reads only the messages no scene holds, one request for every 40, and proposes where the story turns, each with a title and a reason. Tick the ones to keep and save them together; each becomes a chapter of its own. It takes a minute or two and you can close the window.
- **A list instead of two long drop-downs.** In **Pick by hand** (or a message's More menu, Story, Save as a scene) you tap the first and the last message of the scene. A saved scene is one folded row with **Take the mark off**, so messages already in a scene no longer crowd the choice.
- **The Characters column is not cut off.** A fact with a long "Known by" list made its card wider than the column (#353); the cards now fit and the names wrap.
- Also in this app update: a pacing die for the World DM and dice-reading rules for agent If cards (#155).

## Known limits
- Suggest scenes was tried with a fake model only. A real model's scene boundaries may be rough: please try it on a long chat and say what reads wrong. Nothing is saved without your tick.
- A chapter that fails to write (the worker waits ten minutes before retrying) also holds a suggestion back.
- The crash fix was tried with a stand-in for the model program in a real process, not with the real one on Windows. If the crash comes back, send the new report.
- The new strings of the Litopys guide page are translated by a cheap model without a native read.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Apps: Updates > Roleplay > Update. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
