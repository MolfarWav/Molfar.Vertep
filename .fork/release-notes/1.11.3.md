# 🧠 Molfar Vertep 1.11.3

A small release: places drawn on the spot are easier to find, no longer fail with a credit error, and can be given a look of your own. The engine itself is unchanged; everything arrives as **Roleplay 4.94.0, an app update**.

## 🌄 Draw places that have no picture is now easy to find
- In World > Backgrounds the switch **Draw places that have no picture** was only shown after "Change the background by scene" was on and a background folder existed, while the intro text already named it. It is now always listed under "Change the background by scene". While something is missing it is greyed out with a line saying what: the scene switch is off, there is no background folder yet, or image generation is off in Extensions.

## 🎨 A look of your own for drawn backgrounds
- A new field, **Look of the pictures**, sits under that switch. A few English words (`medieval fantasy, candlelight, oil painting`) are added to every background drawn for the chat, for a place drawn on the spot and for a set. They go to the model that writes the description and to the end of the final prompt, so even a new chat with no story yet draws in the right setting. Leave it empty to take the look from the story.
- A place named after a person ("Lyra's private quarters at night") used to reach the model as a bare label. It is now told that this is a name, to leave the person's name out and to take the era and genre from the chat: a fantasy story gets a medieval interior, not a modern one.

## 🛠️ Fixes
- **Drawing failed with "402 Insufficient available credits" on an account that had credit** (reported by the owner on a place drawn on the spot). The call that writes the picture description set no output limit, so a provider that checks credit against the model's whole output limit refused it. It is now capped at 1200 tokens. This also covers portraits and scene pictures, which use the same call.

## Known limits
- Tried in a browser with fake models only: not with a real image backend and not with the provider that returned the 402. If the error still shows after the update, the refusal comes from the image model itself.
- A drawn place is found again by its exact name (any case). If the Dashboard's sensor words the same place differently, it can be drawn again, at most once a minute per chat.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. `dev` only updates the engine, not the Roleplay app. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
