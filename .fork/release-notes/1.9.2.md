# 🧬 Molfar Vertep 1.9.2

Two new things: a **mailbox** where Molfar leaves memory suggestions for you to settle when it suits you, and **letters from your character cards** (Roleplay 4.81.0, an app update). **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## 📬 Molfar's mailbox
- Before, a memory suggestion appeared as a card that held up the end of a run, and if nobody answered it was lost. Now it waits in a mailbox. Molfar's end-of-task suggestions go straight there, with no card.
- The card Molfar shows while you are in the chat has a third answer, **Later**, next to Save and Skip. Later leaves the entry in the mailbox. A card nobody answered, or a run with nobody to ask, also ends up there instead of vanishing.
- Open **Memory and skills** (the brain button). When something waits, the button shows a number and opens on the **Mailbox** tab. Each item says what it is (new memory, update, remove), which memory it belongs to, and why it is here. You can edit the text before you save it. Save writes it the same way a card's Save does (and is recorded in history, so it can be undone); Skip drops it, and Molfar is told not to bring the same entry back. "Skip all" asks twice.
- Skills are not in the mailbox yet.

## 🏠 Roleplay 4.81.0 (app update)
- **Letters from cards.** A card you have not played for a while can write you a short note in its own voice: a chat left for 14 days, a card imported and never played, or a played card you never gave a Soul (that last one writes once). It lands in the inbox as a green **Letter** row with its own filter; it is not a failure and does not turn the badge red. Opening it takes you to the old chat (or starts one, or opens the card's Soul tab). A letter never writes into a chat and does not invent events: it is written from the card and the end of the chat.
- It is **off by default**. Turn it on in Characters, More, **Letters from cards**: the days, the limits (3 letters a day, one per card per 30 days, none while a card's last letter is unread), the model it uses (the Library's model, else the app's default), and the list of cards you told to stop (every letter has a bell button for that).
- Fixed: Characters, More crashed the page ("MenuGroupContext is missing").
- Also in this version: agents can read Dashboard fields (the scene, mood, outfit, goal and the disposition numbers).

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
