# 🧠 Molfar Vertep 1.0.1

The relationship dashboard works with thinking models, including local ones. It comes with the Roleplay app 4.36.0, plus one new switch in the engine for local servers.

### 🧠 The dashboard no longer comes back empty
The dashboard's own model calls (the scene sensor and the soul rating) now think the way the chat's preset says: its reasoning level, its thinking budget and its thinking tags. A thinking budget is added on top of the dashboard's reply limit. Before, a thinking model got no budget there, spent the whole limit thinking and returned nothing, so the dashboard showed empty updates. When an answer is still all thinking, the dashboard now says so and what to change, instead of "the sensor returned nothing".

### 🖥️ Local servers: "The models think"
An OpenAI-compatible connection (llama.cpp, vLLM, LM Studio and the like) has a new switch in Settings › Connections and models, when you add or edit it: **The models think (local server)**. Turn it on for a thinking model, such as a Gemma 4 finetune. The engine then tells the server to think when the preset asks for reasoning, and not to think when the preset says Off. Before, the engine sent such a model no thinking setting at all, so only the server's own settings limited it.

### 📖 The dashboard notices more
The dashboard's event vocabulary grew from 34 to 53 events: teasing, a confession, a shared meal or victory, checking how someone is, thanks, comfort, keeping someone company, jealousy, forgiveness, an attack, manipulation, walking out, a limit respected or pushed, and more. Fewer turns land in "other", where nothing moves. On test scenes in Ukrainian, Russian and English, a cheap sensor model found a usable event in almost every turn.

## 🛠️ Fixes
- Importing many cards at once no longer rates each one with a model call. A single imported card is still rated; the rest are rated when first played.
- The dashboard's note before each reply says the reply stays in the story's language. Small models followed the English notes into English.
- A thinking block written inline before the dashboard's JSON no longer breaks reading it.

## Other changes
- A sensor answer that writes an event id with its family in front (`trust.shared_secret`) counts as that event.
- The dashboard's sensor prompt is about 300 tokens longer with the bigger vocabulary; event groups can still be switched off per chat.

## ⬇️ How to get it
- **The dashboard fixes come with the Roleplay app 4.36.0:** open the launcher and update Roleplay. The thinking settings work on any Molfar Vertep 1.0.0; the local-server switch needs this engine update.
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v1.0.1".
- **Running from source otherwise:** pull the tag `v1.0.1`.
- **Downloads** below:
  - `Molfar-Vertep-1.0.1-<system>` for desktops;
  - `Molfar-Vertep-1.0.1-android-arm64.apk` for Android 9 and newer. It installs over 0.9.1 and later and keeps your data.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v1.0.1` or `:latest`.
