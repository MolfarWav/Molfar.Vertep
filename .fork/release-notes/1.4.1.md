# 🛟 Molfar Vertep 1.4.1

Two data-safety fixes in the engine, and Roleplay 4.68.0 comes with them as an app update.

### ↩️ Undo also brings back your data
When Molfar changes a card, a lorebook or another file under an app's `data/`, the line under his reply now reads, for example, "Changed roleplay · 2 data files · Undo". Before, Undo put the code back and left the data as the run had changed it, and a run that changed only data showed no line at all. Undo asks you to confirm and lists what it will restore. A file you edited yourself after the run is left as it is, and the message afterwards names it.

### 📝 A draft that could not be saved survives a reload
If the browser refuses to store what you typed (its storage is full), Roleplay shows "not saved". Until now a full reload of the page lost that draft. The shell now keeps a spare copy while the tab stays open, and the app starts from it, still marked as unsaved. Closing the tab still loses it, and the line says so.

### 🧩 Roleplay 4.68.0, through an app update
- **Backups carry pictures.** The studio backup zip now includes the gallery images, generated pictures and backgrounds your cards and chats point at, and a restore puts them back. Backups made before this have no pictures and restore as before.
- **Safer HTML in replies.** A reply can dress its message (colours, borders, shadows, rotation, fonts by name) but nothing can pin a box over the whole app or the Send button. `<b>`, `<br>`, `<span>` and `<font>` were being stripped from replies and now work. The fenced html block follows your theme unless it sets its own colours, and has an Expand button.
- **Voices for a Narrator card.** A card that plays several characters can list them under Colors > Voices; each one's quotes get their own colour, found by a name before a colon or the first name in the line.
- **A World DM that invents.** Start from cards builds the setting, the people and the trouble around your characters instead of copying what the cards already say, in four calls however long the cards are. During play the DM no longer records things a character just carries.

Open Updates and press Update on Roleplay. The "not saved" fix needs this engine version too.

## Other changes
- Card skill `edit-large-card` documents the new `voices` field.
- No data format changes in the engine.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
