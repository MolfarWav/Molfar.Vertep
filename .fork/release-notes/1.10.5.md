# 🎭 Molfar Vertep 1.10.5

Presets get smarter. A preset can now know which features are on in a chat, presets you export keep their Choices, and SillyTavern presets arrive the way their authors ship them. The cold Roleplay build no longer gives up on slower phones while it is still working. Most of this is **Roleplay 4.89.0, an app update**. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## 🧭 Presets that know the app around them
- A preset can now ask whether a feature is on in this chat: the Dashboard, Litopys and its recollections, the World DM and its dice, the Data bank, the author's note, and a few more. A rule can sit inside `{{#if vertep.dice}}…{{/if}}`, or a section can carry the condition `vertep.dice`. Such a rule is sent only in chats where that feature can actually speak, so it costs no tokens elsewhere, and a small model no longer acts on a note that never came.
- **Write for me**, **Polish** and the continue nudge now follow the preset's picks, just like the story reply does. A narrator, language or point of view you picked reaches them too, instead of a neutral voice. Presets that do not use picks there send exactly what they sent before.
- The chat's Preset panel shows a **Works with** line under the preset's name: the features the preset has rules for, and which of them are off in this chat.
- Vertep Lite now tells the model that Vertep is the app the story runs in, so a model no longer brings "Vertep" into the story as a place or a power.

## 📦 Export and Import keep your Choices
- A preset you export from Roleplay and import on another computer used to lose every switch: its Choices, the sections they turn on and off, and its groups. Every section then rode at once (for example five narrators together). An exported file now carries all of it, and Import brings it back as an editable copy. A plain SillyTavern file imports as before.
- Presets exported with an older version carry nothing extra. Export them again after the update.

## 🧩 SillyTavern presets arrive as their authors ship them
- With its default picks, an imported preset now sends what the file sends in SillyTavern. Modules the author ships switched off stay off. Before, a module made only of variable lines turned into a variable that was always sent.
- Pick tags on toggles, such as `[PICK 1: MIND]`, become one Choice named after the tag, with clean option names. A `[PICK 1: ↓]` / `[PICK 1: ↑]` pair becomes a choice of two. Pick tags no longer break the preset into strange groups.
- Blocks the author marks "DO NOT TOUCH" or "do not turn off" stay on and are never offered as a switch. A "DO NOT ENABLE" group stays off. The preset editor shows a lock on them.
- The authors' explanations are kept. The first sentence becomes the option's hint, the whole text a note above the block in the editor (never sent to the model). A header's text becomes its Choice's question, and a README prompt becomes the preset's description.
- The import report lists what was kept off, locked, tagged and paired.

## 🛠️ Fixes
- **Roleplay could fail to build the first time on a slower phone** (#190): "Build took too long and was stopped", even with the phone in front and charging. The build had a fixed 5-minute limit and was stopped while it was still working. Now it runs as long as it keeps working. It stops only after 3 minutes with no progress, or after 30 minutes in all, and time the app spends in the background does not count. A second open tab (the app and Chrome at once) no longer starts a second build beside the first one. This was not checked on a real slow phone.

## Other changes
- The repository no longer tracks a local `.agents/` folder. 1.10.4 shipped it by mistake, together with a key file; the key was revoked. If updating to 1.10.4 stopped with "untracked working tree files would be overwritten", rename the `.agents` folder in the engine folder and run the launcher again.
- The preset docs, the preset skill, the guide and the Presets Help article cover all of the above. Help articles point at the right lines of code again.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
