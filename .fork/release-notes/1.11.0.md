# 🧠 Molfar Vertep 1.11.0

A memory model that lives on your computer, installed with one click, and a memory you can finally see. The engine gets the local model and the source choice for embeddings; the rest arrives as **Roleplay 4.91.0, an app update**. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## 💻 An embeddings model on your computer, one click
- Settings > Memory has a new block, **On this computer (optional)**, with two models: **bge-m3** (recommended, 587 MB, strongest on Ukrainian, Russian and English) and **EmbeddingGemma 2** (346 MB, lighter). Press **Download and connect**.
- The engine first installs the small program that runs the model (85 MB, once), then downloads the model. The download is checked against its checksum, an interrupted one continues from where it stopped, and you may close the window while it works. When it finishes, the model is connected for you.
- After that, matching by meaning (memory, the Data Bank, lorebooks) costs nothing and nothing leaves your computer. In Automatic the local model comes first, and your online connection stays as a backup.
- It takes memory only while it works and for ten idle minutes: about 1.1 GB for bge-m3, 0.6 GB for EmbeddingGemma 2. **Delete** gives the disk space back.
- It runs when the engine runs from source or from the npm bundle (under Bun). A compiled build and the phone launcher cannot run it; the block says so instead of offering a button that fails.
- Embeddings now pick their source by themselves: a model already on your computer (LM Studio, Ollama, no key needed) first, then API connections with a key, then OpenRouter. Settings > Memory says how the source is chosen.

## 🔍 What Roleplay 4.91.0 adds (an app update)
- **Memory you can see.** Canvas > Prompt > Memory shows why the last reply carried what it did: which facts went in and their rank, which were kept out and why (the speaker does not know them, no room), the chapters, the Data Bank hits with scores, and what the checks after the reply flagged. "Copy report" gives the same as text. It reads what the plugins already worked out; no extra model call.
- **A card for matching by meaning** says whether it works (off, failing, no vectors yet, partly done, done, made by another model), what filling the gaps costs, and fills them in batches. The engine also fills missing vectors by itself (up to 300,000 tokens for one chat or file; the switch **Make vectors by itself** is on by default).
- **The Data Bank searches by meaning.** A question in other words now puts the right passage first. Words still decide which passages are considered; vectors only order them.
- **Snapshot books.** "Save as a book" in Library > Litopys copies a chat's chapters, arcs and facts to the Data Bank shelf for the chats you pick. A character only gets what they were there for or were told.
- **Memory size is Auto** by default: 15% of the model's window (800 to 16000 tokens). A size you saved yourself stays. 15% is a first guess, not yet tuned on real chats.
- Needs this engine for the card to tell models apart and for the local model.

## 🛠️ Fixes
- **Lorebook entries set to "By meaning" no longer fire on almost anything** with a local model. The old fixed threshold (0.35) was written for a small model; with bge-m3 an unrelated text already scores about 0.41 and with EmbeddingGemma 2 about 0.68. A book now judges its entries against each other and fires the ones that stand out (needs 4 or more vectors; a smaller book uses 0.55), at most 10 per book. After you change the embeddings model, one reply passes without the old entry vectors while they are made again.

## Other changes
- Plugins may say whether a text is a "query" or a "document" (`kinds`), which EmbeddingGemma 2 needs for its prefixes. Other models ignore it.
- Reply requests carry `scanModel`, so a memory plugin ranks only against vectors of the same model.
- The local model has its own shell-only routes (status, download, cancel, connect, delete); plugins and apps cannot reach them.

## Known limits
- Not tried on Windows or on a phone yet. The memory figures above come from one machine.
- The 2.5x boost of the Data Bank and the lorebook threshold are calibrated on test vectors, not tuned on a long real chat.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
