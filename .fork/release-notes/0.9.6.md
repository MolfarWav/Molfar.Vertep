# 🎭 Molfar Vertep 0.9.6

Presets that ask what you want. A preset can now offer options (point of view, tense, reply length, genre, tone…) and switches for whole blocks, and every chat keeps its own picks. Marinara presets import with their options, and FRANKENX 1.6 comes built in. With Roleplay 4.31.0.

## ✨ What's new

### 🎚️ Options for each chat (Roleplay 4.31.0)
A preset can offer choices: pick one (Point of view: Omniscient / Character's / User's) or several (genres), and switch whole blocks on or off (a reasoning plan, sensory detail, colored dialogue). Each chat keeps its own picks.
- Open the switch in a chat's header, **Preset**, then **Choices**.
- Every option shows how many tokens it adds, and the panel shows the preset's total: handy on models with a small window.
- **Reset to defaults** goes back to the preset's own picks. Changes apply from the next reply.

### 🚪 Pick the preset when a chat starts
A new chat opens a short step with the preset and its options. **Start** keeps the defaults if you change nothing. It remembers each character: the next chat with them starts with the preset and options you picked last time. Don't want the step? **Don't ask again**, or the switch in Roleplay's Settings › Chat Behavior.

### 🔀 This chat only
Switching the preset in a chat changes that chat and no other; **Make default** is its own button. When you change the preset or an option mid-story, a muted line appears in the chat ("Point of view → First"), so you can see later why the style shifted. The model never sees it.

### 🧟 FRANKENX 1.6 built in
A simulation-style roleplay preset (by MolfarWAV, from FF5 BOLT and agentX) ships ready to use, with 15 options and 6 switchable blocks. It was adapted to the app: no scene header in every reply (the scene heading and the dashboard already track time and place), no references to tracker agents, and the prose language is an option instead of fixed English. Its instructions take about 13k tokens, so use a model with a 32k window or more. It is read-only: duplicate it to edit the text.

### 📥 Marinara presets
Presets exported from Marinara Engine import with their sections, groups, in-chat depth sections, options and defaults.

### ✍️ For preset authors
In Roleplay's preset editor, Variables gain the **Choice** type (options with a label and the text they insert, one or several, defaults) and on/off switches. Sections read them as `{{name}}`, in `{{#if name == "value"}}…{{else}}…{{/if}}` blocks, or through a section condition (`name`, `!name`, `name==value`). A preset can carry a description, shown in the chat's panel.

### 💬 Discord
The community has a Discord server: the link sits beside GitHub at the bottom of the apps page.

## Other changes
- Molfar's preset skill knows per-chat options: asked to make a block optional, it adds a switch instead of deleting the block.

## ⬇️ How to get it
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v0.9.6". Then open **Updates** in the top bar for Roleplay 4.31.0.
- **Running from source otherwise:** pull the tag `v0.9.6`.
- **Downloads** below: `Molfar-Vertep-0.9.6-<system>` for desktops and `Molfar-Vertep-0.9.6-android-arm64.apk` for Android 9 and newer (installs over 0.9.1 and later and keeps your data).
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.9.6` or `:latest`.
