# 🔥 Molfar Vertep 1.5.0

This release brings the agent forge and a much longer memory to Roleplay (app version 4.70.0), and the engine gives plugins the room these need. Roleplay arrives as an app update, so open Updates and press Update on Roleplay.

### 🛠️ The agent forge
Canvas has a new tab, **Agents**. An agent is a small graph of cards on a board: it reads the chat, asks a model what it needs, keeps its own numbers and notes, and shows results back in the chat.
- Build one by hand from forms, start from a ready recipe, or ask Molfar to write it (the new `agent-craft` skill); a file Molfar writes shows up under "Drafts from Molfar" with the checker's verdict in plain words.
- **Try** runs the agent over a made-up turn with no model call and nothing saved: you see what every wire carried, which cards ran, and what the panel would show.
- In the chat the Agents tab lists the agents a chat uses, with an on/off switch, a Wait switch (the reply waits for the agent, or runs beside it) and a pin for where its results show. Panels sit in bars above the log or in a floating window, choices appear as buttons above the composer, notes fold under the reply.
- Agent sets: Canvas has an Agent sets board, and New chat can pick a set.
- Each agent has its own model and its own call limit in "Model and limit"; the choice stays on your side, so a shared agent never carries your model.
- New cards that cost no model call: Dice, Pick, Extract and Cut. New input sources: Litopys facts and Lorebook entries.
- Agents can ask the model up to 7 times in a row, and independent questions run side by side, paced and tried again after a 429. This needs **engine 1.5.0**; on an older engine an agent with more than two model calls in a row never finishes.

### 🧠 Litopys remembers long stories
- Memory size goes up to 16000 tokens, or **Auto** (15% of the model's context window). The 6-chapter limit is gone.
- When the whole record fits the size, all of it is sent with no ranking, so the provider's cache holds.
- Older chapters merge into arcs by themselves on a new install; an install that already has Litopys data keeps its choice and is offered the switch once.
- "Apply pins and rewrites quietly" applies a suggested pin or rewording at once, with an Undo. Consolidate facts can run by itself after 30 new facts. Retiring and merging facts always waits for you.
- Ranking by meaning: with embeddings set up, facts and chapters are found by meaning beside words, so a story in Ukrainian finds facts written in English. This needs **engine 1.5.0**; on an older engine the ranking is by words.
- The Litopys settings are nine foldable, coloured blocks with a one-line summary each.
- The sentence each memory part opens with can be edited under "Memory wording", and a chat that continues an earlier one but still opens with the card greeting shows a note about it (#113).

### ✨ Small things
- The Dashboard moves a little: bars glide to the new value, new rows fade in, and the weather line has an icon that matches the words (nothing moves with "reduce motion" on).
- A persona has a dialogue colour.
- Vertep Lite can draw an in-world object (a phone screen, a letter, a sign) as one small HTML panel; a pick turns it off.

## 🛠️ Fixes
- Structure it reads a reply that puts the sections at the top level, and says which keys the reply had when it filled nothing.
- On Linux a plugin's `fs.stat` of a folder reported 4096 as its size; it is 0 on every system now.

## Other changes
- Plugin manifests may carry `limits: { passes, concurrency }`; an `llmRequest` hook can read `ctx.turn.scanVec` and `ctx.turn.contextTokens`.
- CI is green on `main` again (#114): the edge TTS tests use a local fake of the service.
- No data format changes in the engine.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Then open Updates and update Roleplay to 4.70.0. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
