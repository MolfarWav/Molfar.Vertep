# 🎭 Molfar Vertep 0.9.11

One fix, and an important one if you use OpenRouter: Molfar now runs on the model its picker shows, even if you never picked one yourself.

## 🛠️ Fixes

### 🎯 Molfar runs the model its picker shows
If you never opened the model picker on Molfar's page, the picker showed the first model you had ticked in Settings > Models, but Molfar's requests went out with no model at all. The engine then took the first model of the whole catalog, sorted by name. On OpenRouter that is the `~anthropic/claude-fable-latest` alias, so a player who had ticked one cheap model was billed for Claude Fable. 0.9.10 did not catch this, because that alias is a real, available model.
Now Molfar's page sends the model it shows, and the engine, when no model is named, takes the first one you ticked, just like the pickers. If you already picked a model by hand, nothing changes for you.

You can check which model a request really used in the prompt inspector on Molfar's page: hover over the model name to see the full `provider/model` id.

## ⬇️ How to get it
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v0.9.11".
- **Running from source otherwise:** pull the tag `v0.9.11`.
- **Downloads** below:
  - `Molfar-Vertep-0.9.11-<system>` for desktops;
  - `Molfar-Vertep-0.9.11-android-arm64.apk` for Android 9 and newer. It installs over 0.9.1 and later and keeps your data.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v0.9.11` or `:latest`.
