# 🧠 Molfar Vertep 1.11.4

A small release: lorebook entries get folders, and a chat gets its own stylesheet. The engine itself is unchanged; everything arrives as **Roleplay 4.95.0, an app update**.

## 📁 Folders in lorebooks
- A big book can be tidied into folders, like a notes app. Press **New folder** beside **Add entry**, or open an entry and pick **Folder**, or use **Select several > Move to folder**. Once a book has a folder, the Entries tab is a tree: folders first (each with its entry count and tokens), then the entries with no folder.
- Folders nest up to three levels: the folder menu has **New folder inside**, or type `Places/Taverns` as a name. Counts and **Enable all** include the folders inside; renaming a folder takes the ones inside along; removing one moves its entries and folders up a level.
- On a computer, drag an entry (or all ticked ones) onto a folder or onto **No folder**. A folder can wear one of six colours (menu: **Name and colour**). A phone uses Move to folder.
- Search and the filter chips open the folders that have a match and say "3 of 41". Which folders are open is remembered per book in the browser.
- A folder is only a label: the prompt engine ignores it, and it is not the **Group** setting. Books and exports from before read the same.

## 🗂️ An entry opens in a drawer
- On a computer an entry slides in from the right over the list instead of replacing it. A phone keeps the full page. The book header, the tabs and the toolbar were repacked so no row holds one small control.

## 🎨 Chat CSS
- In a chat, **More > Chat CSS** (after Voice colours) is a stylesheet for that one chat: it shows as you type, Save keeps it with the chat, closing without Save puts the old look back. Four examples are built in. It affects only that chat and is not copied when you fork or continue it in a new chat.

## 🛠️ Fix
- **A long lorebook entry no longer traps scrolling on a phone.** The content box grew to the whole text and filled the screen, so nothing but the box was left to touch. It is now capped at about half the screen and scrolls inside.

## Known limits
- The phone scroll fix is argued from the layout, not reproduced: the test browser's touch scrolling does not move anything even on a plain page. Tell us if a long entry still traps your finger.
- Tried in a browser at 1280, 1000 and 390 px; drag and drop is mouse-only. Translations of the changed guide pages (Memory, Settings) are still English until they are refreshed.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. `dev` only updates the engine, not the Roleplay app. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
