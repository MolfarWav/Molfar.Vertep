# 📚 Molfar Vertep 1.12.2

No engine code changed. **Roleplay 4.103.0 arrives as an app update**: the Help is fuller, and the guide reads in your language again.

## 📖 Six new Help articles
- Open "?" in Roleplay and search: **the chat shelf of the Canvas** (search, sort, "Add chain"), **the World tabs** (Overview, Places, World book, Runs), **the Constellation map** of how a character feels about you, **the model for card tasks**, **the opening hint** under a continued chat, and **the /gallery dialog**. Each is in English and Ukrainian and says where the feature is and what it does not do.
- The Tool Calling article now says what happens when a model cannot use tools: the reply fails with "No endpoints found that support tool use". Switch the tools off (or pick another model) and the chat answers again. Many free models cannot use tools.
- The World DM tip no longer says the DM is off until you pick a level: a story chat starts at Chronicler.

## 🌍 The guide in 13 languages
- Five pages of the Roleplay guide (Canvas, Litopys, Long chats, Memory, World DM) and the engine's "Settings" page were out of date in German, Spanish, French, Italian, Japanese, Korean, Dutch, Polish, Portuguese, Russian, Turkish, Ukrainian and Chinese, so the reader showed English. They are translated again. No native speaker has read them yet: if a line reads wrong, tell us.

## 🛠️ Fixes
- Pressing Enter in a number field of the Litopys settings now saves it. It saved only when you left the field.

## Other changes
- The browser-check mock model can refuse tools, for checks (`POST /__refuse-tools`).

## Known and left
- A model that refuses tools still shows the raw error text in a red toast; a friendlier message is planned (Molfar.Vertep#306).

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. `dev` only updates the engine, not the Roleplay app. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
