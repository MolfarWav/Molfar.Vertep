# 🧬 Molfar Vertep 1.10.2

An engine release: **app screens open much faster**, and a **user guide** arrives in Help. There is no app update in it.

## ⚡ Apps answer in tens of milliseconds, not a second (#232)
- Every request an app makes to its plugin used to cost about a second, and several at once waited in a line (four took four seconds). A screen that asks for ten things took ten seconds. On a test workspace of 3000 files: a small request **975 → 17 ms**, a larger one **1010 → 50 ms**, a save **1020 → 21 ms**, four requests at once **3970 → 200 ms**, eight at once **7800 → 170 ms**.
- The engine now keeps 2 to 4 workers for plugins instead of one, and no longer checks the whole workspace for changes before every answer: the history entry is written right after the answer.
- Safer than before in one place: a request that had already finished its work could come back as an error ("sandbox aborted") when the plugin runtime failed while closing. It now returns the result.
- Requests that change an app's files still go one at a time per app, so two saves cannot overwrite each other. Reading requests run side by side.
- What you may notice: when many requests come in a burst, the history (Undo) gets **one entry for the burst**, for example `app(notes): GET /big (+38 more)`, not one per request. If the engine is stopped in the middle of a burst, the files are saved, only their history label may be lost.
- `MOLFAR_VERTEP_SANDBOX_WORKERS` sets how many workers (2 to 4 by default, 8 at most).

## 📖 A guide in Help (#230, #225)
- Help now has **Tips** and **Guide** tabs. The guide is ten linked pages (what Molfar Vertep is, first steps, apps, models, settings, devices) in your language, and every app can add its own pages.
- Molfar reads the same pages when you ask how something works, so he answers from the guide instead of searching the code, and stops proposing new apps to people who only want to use one.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
