# 🎭 Molfar Vertep 1.0.5

Roleplay on a phone gets a new chat header and menu, replies survive a locked screen, and presets remember your choices. Everything here comes with the Roleplay app 4.41.0.

### 📱 A chat header made for phones (Roleplay 4.41.0)
The phone chat header used to be a row of about nine small icons with no labels. Now it shows the character's portrait and name (a long name scrolls slowly), the chat's title, a ring with how full the context is, and one **Menu** button. Tap the portrait for the card, the soul and the full picture. Tap the ring for the chat's details: model, tokens, context.

**Menu** slides in from the side. On top: who you play as, then big **Preset** and **Model** buttons that unfold their choices in place. Below: everything you do with this chat (find, next chat, author's note, lorebook activity, story record, branches, bookmarks, display, new chat, delete messages, chat files). The other sections sit at the bottom under **Go to**. The "+" next to the message box keeps only quick actions: regenerate, continue, impersonate and the compose tools. The scene strip shows a small dashboard chip, so it is clear that a tap opens the dashboard.

### ⏳ You can see the model working, and the reply comes back (Roleplay 4.41.0)
While the model works, the empty reply shows moving dots and, after a few seconds, how long it has been writing ("Writing · 12 s"), instead of a static "…".

On a phone, switching to another app or locking the screen mid-reply could leave "…" forever until a reload. Now, when you come back, the app checks whether the reply was already saved and shows it.

New in Settings, Streaming (and in the chat's Display sheet): **Show replies** as the model writes them, or only when they are finished.

### 🎛️ Your own default preset choices (Roleplay 4.41.0)
Presets with options (FrankenX has 22) lost your picks in every new chat. In the chat's preset choices there is now **Save as my default**, for stock presets too. New chats with that preset start with these choices. A character that already has a chat still starts from the choices of its last one. **Use my default** and **Forget my default** sit next to it.

### 💬 Regenerate with a hint (Roleplay 4.41.0)
**Regenerate with a hint…** in the "+" menu opens a field: write what the new reply should do differently ("shorter", "she has not forgiven him yet"). The hint goes to the model for that one reply, as the last instruction, and is not saved in the chat. It always makes a new variant, so the old one stays a swipe away.

### 🌐 Translate one field, or a whole lorebook (Roleplay 4.41.0)
The card editor has a **Translate** button on Description, Personality, Scenario, First message, Example dialogue and on each alternate and group greeting. It translates that one field into the card's translation language, and the notice has **Undo**.

Lorebooks can be translated too: the translate button in a book's header translates every entry. Translated keywords are added next to the original ones, so entries fire in both languages. By default it keeps a copy of the book as it was.

These buttons use the translator chosen in **Tools, Translation**, which includes Google, Lingva and DeepL: no model and no tokens needed.

### 🗂️ Tab rows on phones (Roleplay 4.41.0)
Tabs that ran off the screen gave no hint. Now the side with hidden tabs fades and shows an arrow that pages the row, and the open tab stays in view (card editor, group editor, preset editor, samplers). Tools wraps its tabs onto a second line.

## 🛠️ Fixes
- On Chrome and Brave for Android, the lower part of a chat would not scroll by touch when a character's expression sprite had not loaded.
- After Stop and regenerate, switching variants with the arrows could show the same text on every variant. Each variant now keeps its own thinking and tool steps.
- The dashboard no longer updates after a reply with no text (only thinking, or a model error), so no tokens are spent on it.
- In the new-chat dialog, options picked before the character's remembered choices loaded were undone by them.
- Stock presets: the Samplers page tabs could not be opened. The Groups block in the prompt manager now says in plain words what a group does.
- Streamed text keeps up with fast models: it no longer lags far behind the real reply.

## Other changes
- Roleplay: your default preset choices are stored in `data/preset-defaults.json`.
- Browser check (for contributors): the mock model can wait before answering and stream a reply word by word.

## ⬇️ How to get it
- **The Roleplay changes come with the app 4.41.0:** open the launcher and update Roleplay. It works on any Molfar Vertep 1.0.0.
- **Launcher users:** run `Molfar-Vertep.bat` and answer **Y** to "Update to release v1.0.5".
- **Running from source otherwise:** pull the tag `v1.0.5`.
- **Downloads** below:
  - `Molfar-Vertep-1.0.5-<system>` for desktops;
  - `Molfar-Vertep-1.0.5-android-arm64.apk` for Android 9 and newer. It installs over 0.9.1 and later and keeps your data.
- **Docker:** `ghcr.io/molfarwav/molfar-vertep:v1.0.5` or `:latest`.
