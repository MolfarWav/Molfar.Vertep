# 🧠 Molfar Vertep 1.11.6

No engine code changed. **Roleplay 4.97.0 arrives as an app update**: characters now believe each other's lies, and Litopys can ask only about the risky changes.

## 🤥 A lie is believed by the people who heard it
- When the Dashboard's sensor marks a statement as a lie told in front of others, those people take it as true in their own replies ("Bram was told by Ada: ... and has no reason to doubt it"). The liar's own line still says it was a lie, and someone else speaking does not repeat it.
- In Dashboard > Said, open the lie (Show hidden): **Believe it:** lists who believes it. Press a name when that person finds out. The sensor also ends the belief when a reply shows the truth coming out, and removing the lie removes every belief.
- The row's menu has **This was a lie** (for a statement the sensor did not call one) and **Not a lie** (when it got it wrong).
- After the Dashboard's usual note age (30 turns) an old lie becomes a fact of the new type **Belief** in the Library, kept in that person's section only ("Bram believes, told by Ada: ..."). **Knows the truth now** ends it and tells the Dashboard. The Memory view marks a belief, beliefs never go into a card's memory, and the leak check no longer treats a belief as a secret.
- No extra model call.

## 🛡️ Only risky changes wait
- Library > Litopys settings > Suggestions has a third choice, **Only risky ones**. It is the default of a new install; an install that already had data keeps what it chose.
- Routine suggestions (pin, reword, retire, merge) are applied at once, written in Activity, and have an **Undo** (it now also takes back a retire and a merge).
- These wait, each with the reason on the card and in the Inbox: a merge that would tell more people a fact only some knew, a change to something you pinned, wrote, edited or marked key, a lasting change or a belief fact, and a new fact that may contradict one you pinned. A new "change" fact and the beliefs of a lie wait as **Add a fact**.
- Decided in code, no model call.

## Known and left
- Not checked with a real model: whether the sensor retires a belief when the truth comes out, and whether the chapter worker still writes a lie as a fact despite the hint. The "at most 3 waiting per 100 replies" target is not measured on a real long chat; the "may contradict" rule is a guess by shared words.
- The guide translations of the Dashboard, Litopys, Memory and Settings pages are stale (the reader shows English until they are refreshed).
- A suggestion made before switching to the new mode is sorted at the next chapter or Consolidate.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. `dev` only updates the engine, not the Roleplay app. Downloads and the Android APK are on this release page.
