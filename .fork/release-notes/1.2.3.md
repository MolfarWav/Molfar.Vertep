# 🧭 Molfar Vertep 1.2.3

Molfar reads the files you give him and hands back the files he makes. ComfyUI workflows go in as they are exported, and the start script gets a menu.

### 📎 Files in Molfar's chat
Attach a text file, JSON, Markdown, CSV or a Word document, not only a picture. Molfar reads it with your message. The file is kept in your workspace under `uploads/`. A PDF is not read yet: its tile says so.

### 🔗 Files Molfar makes open with a click
When Molfar names a file he wrote, the name is a link: a click opens it, the icon next to it downloads it.

### 🎨 ComfyUI: import the workflow
Settings → Images → your ComfyUI server → **Import workflow file…**. Take the file from ComfyUI's Workflow → Export (API). The size, steps, CFG, sampler, scheduler, clip skip and LoRAs land in the form, and the workflow gets the placeholders it needs. A workflow pasted by hand gets them when you save.

### 🚦 A start menu in Molfar-Vertep.bat
Start, start without updating, update, the dev branch, the previous release, a setup check or a reinstall: one key each. Without a key it starts after 5 seconds, as before. The menu sits next to the Molfar star drawn in coloured blocks, and the messages are coloured too: a step in gold, done in green, a note in yellow, a failure in red.

## 🛠️ Fixes
- **Sign-ins that broke on a model check** ("invalid_grant"). Two refreshes at once could throw away a valid sign-in. Sign in once more under Settings → Connections; it should then stay.
- **Roleplay Dashboard:** a persona you switched away from in a chat no longer shows up as a character.

## Other changes
- **Roleplay:** a character card's Profile can describe several characters, for narrator cards with a cast.
- The program also answers to its new name: the `molfar-vertep` command and the `MOLFAR_VERTEP_*` settings. The download still contains `chrysalis.exe`; the switch comes in a later release.

## How to get it
From source: `Molfar-Vertep.bat` picks up the new release. Downloads: the archives and the Android APK on this release page. Full list: [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
