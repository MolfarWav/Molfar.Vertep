# 🎨 Molfar Vertep 1.20.0

An engine release with **RunPod Serverless as an image server** and a **longer time limit for Script cards**, which fixes the stock Repetition guard failing with "the script ran longer than 500 ms". **Order:** get this engine release and restart first, then press Update for Roleplay 4.141.0 and Social 0.22.0 (Updates dialog); they do not need this engine, but the Repetition guard fix and RunPod are in the engine.

## ☁️ ComfyUI on RunPod Serverless
In Settings > Images, add a **ComfyUI** server and use `https://api.runpod.ai/v2/<your endpoint id>` as its address, your **RunPod API key** as the key, and the checkpoint file names of your worker under **Models** (RunPod cannot list them). The picture is drawn on your worker with the same workflow settings as a local ComfyUI:
- the job is queued, followed until it ends (a cold worker can take up to half a minute to start), and cancelled if it is still running after ten minutes, so the worker stops billing;
- **Check** asks the worker's health, so a wrong endpoint id or key shows at once, not at the first picture;
- the official `runpod/worker-comfyui` worker is the one this was written for (its picture comes back as base64 or as a link; older workers that answer in `output.message` work too).
Not tried against a real RunPod endpoint before release: it was tested against a mock only. If it does not work for you, the error text names the step.

## ⏱️ Script cards may run longer
A Script card (the agents' small scripts) had half a second to run, read off the clock, so a busy computer or several agents at once pushed the stock **Repetition guard** over the limit and it failed on every run. A script now has 1.5 seconds, the worker is ended after 3.5 seconds, and all the scripts of one run share 4 seconds. Scripts that loop forever or eat memory are still stopped by the same limits. Roleplay 4.141.0 also makes the stock Repetition guard do about half the work (an agent you already installed keeps its old script but gains from the new limit).

## Other changes
- The Images page of the in-app guide describes the RunPod setup (translated into the 13 languages).
- Settings > Images: one new line of help for ComfyUI in the 14 languages.

## 📦 What arrives through app updates
- **Roleplay 4.141.0:** colours of dialogue that find their speaker better (a name nobody listed gets a colour of its own, "she" and "he" point at the one character of that gender named earlier, a short quoted word in a sentence is not painted as speech), a switch that shows who was picked and why, and the faster stock Repetition guard.
- **Social 0.22.0:** on a phone, "More" is a page of icon tiles (Your profile, Journal, City, Settings) and Settings is seven groups that open and close; plus moving a building on a district's drawing.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
