# 🧬 Molfar Vertep 1.9.3

The Agent forge gets its leftovers: try an agent on a **real chat**, two ready **map agents**, a clearer **install and permissions** flow, and **agent sets** that show who uses them. Most of it is **Roleplay 4.82.0, an app update**. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay. (Molfar's new tool needs the new Roleplay.)

## 🧪 Try an agent on a real chat
- In the agent editor, the **Try** tab has **A real chat**. Pick one of your chats and the boxes fill with what the agent would get there: the last reply, the history, facts and Dashboard fields (an empty one is named), plus the memory the agent keeps in that chat. The chat is only read, never written.
- **Run with the model** asks the chat's model (or the one you set for the agent) the agent's questions once. It shows the model and the most calls it can make before you press it. The answers land in the boxes, so every later trial costs nothing and a bad answer can be edited and replayed.
- **Molfar can do the same.** The built-in agent has a new tool, `agent_dry_run`: it runs a draft or an installed agent over a real chat and reads back what the chat gave it, each question, what every wire carried and what the agent would write and show. By default no model is called; a run on the chat's model costs tokens, so you confirm it first (no question for a local model or with cost checks off). Molfar's agent-craft skill now says to try a draft on a real chat before handing it over.

## 🗺️ Map agents and a grid widget
- The Forge's **Start from a ready agent** list has two new agents. **Story map** keeps the places the story visits and draws them on a map in the floating window; the code, not the model, decides what counts as a new place. **Territory board** keeps a board of 8 by 6 tiles (seen, ours, danger, settlement).
- A new **grid** panel widget draws the board. You bind it to a list and set columns and rows (up to 16), and a legend of up to 8 states. Each state has a tone and a mark, so colour is never the only sign. The Forge has a form and a preview for it, and the checker names a wrong size, field or legend.

## 🧩 Agent sets: who uses them, what is remembered
- The Agent sets screen and the chat's set list say **used by N chats**. Saving a set that chats follow shows a warning, and the delete confirm carries the count. A chat with its own copy is not counted, because a change does not reach it.
- A new chat with a character (or group) **opens on the set its last chat used**, and says so. If that set is gone, it falls back to the default.
- One switch, **Agents' notes in chats**, moves every note out from under the replies. Choices, panels and the Agents line stay. It is global; there is no per-chat override.

## 🔐 A real permissions page
- An agent's permissions are one dialog: needs grouped, one switch each, progress, and **Allow all**. It also lets you pick a model for each role before the first run, and says plainly that the agent starts only when every line is on. It opens by itself after an install.
- A permission is marked **New** only when a later version of the agent added it.
- The checker's error codes now have plain sentences (English and Ukrainian) that name the card and a way out; the code stays as a small chip.
- Panels and widgets in the Forge can be **reordered by dragging** (hold on a phone). Up and Down still work.

## Other changes
- Molfar's `agent-craft` skill knows the `html` widget is drawn (it said it was not) and knows both map recipes.
- Dev only: `browser-check` can now run Forge checks on the real Roleplay app against the fake model.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
