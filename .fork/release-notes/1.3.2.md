# 🧾 Molfar Vertep 1.3.2

A new chat header, a tidier card editor on a phone, lorebooks you can tell apart, and a Story record settings page you can read. All of it is Roleplay 4.63.0, which comes as an app update; the engine itself has no code change in this release.

### 🧭 The chat header (#109)
The tools you reach for while playing moved out of the three-dots menu into the header: **Note**, **Lore**, **Record** and **World**, each coloured, each with its state at a glance: a dot when the author's note has text, how many lorebook entries fired on the last scan, how many chapters the story record has, and the World DM's status. A dashed **~N tok** button opens the "What this chat carries" panel; the strip of chips under the header is gone. On narrower windows the buttons keep icons and counters, and below that they go back into the **More** menu. On a phone the same four are coloured tiles at the top of the chat Menu. The preset, persona and model switch is unchanged.

### 📚 Lorebooks (#63)
Every book in the list has an icon for how it is tied to cards: the card's own book, a book shared by cards, or a book no card uses (global books keep their globe). The filter has the same icons and a new split: Global, Own to a card, Shared by cards, Not linked. The list is wider, the book name has its own row, **Import** is a button next to New instead of hiding in the menu, and a book can now be **exported** as JSON (importable again).

### 🪪 The card editor on a phone (#63)
The header is three rows instead of a pile of chips: who it is and **Chat**; three coloured tiles with the card's tokens, permanent tokens and chats; and one row of icon tools. The **chats** tile (and the "N chats" badge on desktop) opens your Chats list narrowed to that card. The portrait on Core is smaller and sits beside Name and Tags. While you have unsaved changes, Chat turns into an outline button so **Save changes** is the one filled button.

### 📖 Story record (Litopys) settings
The settings are seven bordered blocks with a short title and one line of what each is for: Record, In the prompt, Writing the record, Arcs, Skills, Notices and Facts. Nothing was renamed or changed in what it does.

### 🔦 "Show me" in What's new and Help (#87)
The button no longer promises a place it cannot open: for a tip about a chat when you have no chat yet, a line says so instead. A tip that needs an open chat opens your newest chat rather than the chat list, and the guide waits for its target (the chat menu, the Dashboard, a book or preset) instead of giving up after a fixed half second, so a slow phone gets there too.

### 🎨 One primary colour (#63)
**New character** on Home is the same primary colour as every other main button; the separate red variant is gone.

## Other changes
- Guide tips that pointed at the chat menu now point at the header, and a What's new tip announces the header.
- Author's note, Lorebook activity, Story record and World DM are also in the **More** menu when the header is too narrow for them.

### Known
On a phone, the What's new card overlapping the Achievements card on Home and the rail target inside More (#87) were not re-checked in this release.

## Get it
Run from source with `Molfar-Vertep.bat` (latest release tag), or download the archive for your system from the assets below. Everything above arrives as an app update through the Updates panel.
