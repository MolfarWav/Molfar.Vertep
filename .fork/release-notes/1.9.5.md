# 🧬 Molfar Vertep 1.9.5

Characters know even less than before, and Roleplay now **warns you when a character acts on a secret it should not know**. This is **Roleplay 4.84.0, an app update**; the engine itself has no code changes in this release. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## 👁️ A warning when a character knows too much
- After a reply, the app compares it with the story's secrets (the facts only some characters know). When a character who does not know one speaks or acts as if they did, a quiet amber note appears **under the reply**: who it is, the line that gave it away, and the secret.
- Three answers: **Regenerate reply** (only on the newest reply), **"<Name> found out"** (the story record now says they know it, and the Activity tab shows the change) and **Not a leak**.
- Until you answer, that character learns nothing from the reply: what they would have noted about your character is not kept, and the chapter writer is told the reply is not canon and does not make them a knower.
- It costs almost nothing: in Sensor mode the check rides in the call that is made anyway. In Fast and Manual modes it is one short extra call, made only when a reply resembles a secret.
- It is on by default. The switch is in the Dashboard settings, "How it reads": "Warn when a character acts on a secret it should not know".
- How well it works: on 288 test replies, 84 of 100 warnings were right and it caught 63 of 100 real leaks (a small local 9B model: 96 and 71). Paraphrases get through ("the missing princess" said as "the king's niece"). Only secrets of the story record are checked, not the Dashboard's own notes. Read these as a direction; the sample is small.

## 📖 Chapters follow who saw the scene
- A chapter now remembers which characters were in its scene. A character's own reply no longer carries a chapter that character did not witness, nor an arc built from one. A narrator's reply still gets every chapter.
- Chapters written before this release have no such list and stay visible to everyone until you rebuild the record.

## 📚 Lorebooks: import and export
- The list header used one up arrow for Import, which looks like export, and had no export. Import now has the arrow into a tray, and a new **Export** button opens a menu: the open book as one JSON file, or **all books in one zip** (one JSON per book, readable by Import). A book that cannot be read is skipped and the message says how many.

## 🛠️ Fixes
- In the Memory overview (Library, Litopys) the "..." menu of a fact sat under the scrollbar and could not be pressed.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
