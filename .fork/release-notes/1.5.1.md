# 🔄 Molfar Vertep 1.5.1

A small release with one fix that matters: changes to a built-in preset now reach the copy you already have. Roleplay 4.71.0 rides with it as an app update. **Update in this order:** get this engine release and restart, then open Updates and press Update on Roleplay. Done the other way round, the preset refresh has no new template to copy from.

### 🔄 Built-in presets follow the shipped text
Before, a change to FRANKENX, Molfar or Vertep Lite reached only new installs. If you installed Roleplay earlier, your copy kept the text it had on the first day. That is why the HTML panels pick that came with Roleplay 4.70.0 never showed up in your Choices. Now every app update compares each read-only built-in preset with the one the app ships and takes the shipped text when they differ. A preset you duplicated and made editable keeps your text. The engine side: an update now replaces a changed template file under the app's `data/` (it only added missing ones before). The update saves your workspace to its history first, so the old text is not lost.

### 🎭 Vertep Lite: HTML panels and a Fiction frame
- **HTML panels** (on by default, Off in Choices): when a scene focuses on a phone screen, a letter, a sign or a HUD, the narrator draws it as one small HTML panel. This is the pick from 4.70.0 that now actually arrives. The same refresh also brings the rule from 4.69.0 that asks the model to name the speaker by name in the same paragraph as each line.
- **Fiction frame** (new, Off by default, in Choices): for models that refuse, soften or lecture on dark themes. When it is On, a short block says the story is fiction for adults and dark material (slavery, war, cruelty, coercion, desire) is written the way the world has it, with no disclaimers and no leaving the story, and a one-line reminder follows your newest message. Everyone in a sexual scene is an adult in the story; a child never takes part. It costs about 250 tokens while On and nothing while Off, and it is not tied to one model. How well it works depends on the model, so try it on a scene a model refused and tell us what still gets refused.

### 🧩 Agents: a block for results
In a chat's Agents tab, the place button of an agent has a new switch, "Also show in the block". An agent with it on keeps its latest result (notes, hints for the next reply, choices, changes to its state) in a folded block above the message box. The block stays when the history scrolls away. It is per chat and never goes to the model.

### 📚 Help: 66 more articles
Most features in Help now have a longer text behind "More": what it is for, where to find it, what is on by default, what it does not do. They cover Profile, Soul, Habits, Voices, Persona, Groups, the Dashboard, Litopys, the World DM, the Prompt board, Lorebooks, Presets, Regex, the Inbox, Themes, every Tools tab and the Settings sections, in English and Ukrainian. Search now ranks the best match first and also reads the article text.

## Other changes
- A hint typed by hand into a read-only built-in preset is replaced by the shipped one on update.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
