# 🧭 Molfar Vertep 1.21.0

A small engine release: **the built-in agent stops reading in circles and writing from memory**, and **plugins can read many files in one call**, which makes Roleplay's prompt building faster on a big workspace.

## 🔎 The agent no longer mistakes a cut result for an empty one
Three causes of "the agent writes from memory and reads the same file again and again" are closed:
- **Search in one file works.** `grep` given a path that is a single file used to search nothing and answer "(no matches)", so the agent decided text it could see was not there. It now searches that file (credentials and protected files are still refused), a path that does not exist is an error, a leading `(?i)` works, `\p{L}` is a Unicode class, and an empty answer says how many files were searched.
- **A cut result says what it is.** To save tokens, older tool results are cut on each model call, and the cut looked like an empty or failed result. The marker now names the call (a batched read lists its files), says the result was not empty and the call did not fail, and says to read again before quoting or editing. The system prompt and the small-window rules carry the same line and forbid quoting or editing file content from memory. The cut sizes are the same, so the cost is the same.
- **Memory changes show what goes.** Proposing a memory change with `replaces` removed the whole entry that held the phrase. The confirmation card now shows that entry, and the tool tells the agent to keep what should stay. An entry that brought its own date no longer gets a second one.

## ⚡ Plugins read many files in one call
`host.fs.readMany(paths)` answers a list of texts in one call, under the same limits as a single read (nothing outside the app's data folder, no links followed; at most 5,000 paths and 32 MB). Roleplay read each of its 161 regex scripts as its own call, about half a second on every pass that builds a prompt. Measured in the real sandbox: 440 to 530 ms one by one, 35 ms with `readMany`. An app that wants it checks that it exists, so an older engine still works.

## 📦 What arrives through app updates
- **Roleplay 4.147.0:** you can edit the Dashboard's story clock by hand (time, part of day and day); the Character growth agent keeps a separate portrait for each character of a card that voices several (a narrator card), and the Memory tab lets you assign blocks to a character; and the regex scripts load in one call on this engine. Install the new Character growth agent (2.1.0) to get the per-character blocks.

Press Update in the Updates dialog to get them.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
