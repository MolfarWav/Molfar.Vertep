# 🧭 Molfar Vertep 1.2.2

Fresher model lists: the engine's model library moves up a big step (about 330 more built-in models), and OpenRouter, DeepSeek and Moonshot now also add the models they started serving since. Plus a fix for a black screen in Settings → Connections.

<!-- DRAFT: ships after 1.2.1; check every line against the code before the release. -->

### 🧭 Newer models in every built-in provider
The built-in providers (OpenAI, Anthropic, Google, OpenRouter, DeepSeek, Z.AI and the rest) take their model lists from the library the engine runs on. That library moves from 0.85.1 to 1.2.0: about 1,550 models instead of about 1,230. Anthropic's newest models now come from that list with their real settings. Before, the engine added them by copying an older model's settings, and some of those settings made the requests fail.

### 📡 Models a provider added since, straight from the provider
OpenRouter, DeepSeek and Moonshot are now asked for their current model list when the app starts. Models the built-in list does not know yet show up next to the others. On OpenRouter they come with their context size and price (about 85 extra models at the time of writing, free ones among them). The built-in list still decides everything about the models it knows.

## 🛠️ Fixes
- **Black screen when adding a model by hand** (#59). In Settings → Connections, typing the second character of a model id in a manual model list turned the whole app black. It no longer does.
- **A connection's model list that fails now says why** in the engine log (`model list failed:` with the reason). Before, a connection whose list could not be read simply showed no models.

## Other changes
- The model library is pinned to an exact version, so every computer runs the one that was tested.
- Some models left the built-in lists: Moonshot's Kimi K2 models, DeepSeek's `deepseek-v4-flash` (now `deepseek-flash`), six Z.AI Coding CN models. A chat set to one of them asks you to pick another model.
- The Azure provider is now called `azure`; saved Azure connections and keys move over by themselves.

## How to get it
From source: `Molfar-Vertep.bat` picks up the new release. Downloads: the archives and the Android APK on this release page. Full list: [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
