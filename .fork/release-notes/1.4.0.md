# 📲 Molfar Vertep 1.4.0

Molfar Vertep can now be installed like an app. This release also makes the image provider's errors readable in your own language.

### 📲 Install Molfar Vertep as an app
Open the account menu and press **Install app**. On Android (Chrome, Edge, Samsung Internet) and on a computer, the browser shows its install dialog. On an iPhone or iPad the menu tells you where Safari keeps it: **Share, then Add to Home Screen**. Afterwards Molfar Vertep opens from its own icon, full screen, without the browser's address bar and tabs, so it is no longer lost among other tabs. The controls stay clear of the notch and the home bar, and the status bar takes the colour of your theme.

If the engine is off, the app shows a "not reachable" page in your language that reloads by itself once the engine answers. Nothing else is cached, so an update reaches the installed app exactly as it reaches a browser tab.

One catch: browsers install apps only from a secure address (`https://`, or `localhost` on the same computer). A phone that opens your computer at `http://192.168.x.x` gets no install offer; the dialog says so and links to the guide. The README section **Install as an app** explains the two ways to get https: Tailscale (`tailscale serve`) or a certificate of your own.

### 🖼 Image errors in your language
In Settings > Images, the provider's problems (wrong key, no credit, rate limit, unknown model, server not reachable, timeout) now appear in the interface language instead of English only. Check, Edit, Add server and the footer links (GitHub, Discord, Report a bug, Help) are 40 px tall on phones, so a thumb hits them.

### 🧩 Roleplay 4.67.0, through an app update
A character's skills are now called **habits** (in Ukrainian: звички) in the card's Memory tab, the Library, the Litopys settings and the prompt; old data keeps working, and the word skills stays for Molfar's own skills. **Write for me** can translate your own message in place, with Undo. The Prompt board and Backgrounds fit a phone better, and Show me opens the More sheet when its target is there. Open Updates and press Update on Roleplay.

## Other changes
- The engine serves `/manifest.webmanifest` and `/sw.js` at its root; no data format changes.
- New What's new tip for the install button.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
