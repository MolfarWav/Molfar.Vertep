# 🏠 Molfar Vertep 1.14.0

A small release: one engine feature, and two app updates that use it. **Order:** get this engine release and restart, then press Update on **Roleplay** (4.105.0) and **Social** (0.5.0) in Updates.

## ⚙️ App settings are in the shell's Settings
Roleplay's chat look and behaviour (Chat Behavior, spell check, streaming, themes) lived only on its own "Roleplay settings" page, and nothing in the shell's Settings pointed there. Settings now has an **App settings** group at the top. It lists every app that names a settings page of its own, and a click opens the app on that page. Roleplay appears there as **Vertep** (that is the name in its manifest). The list shows apps only after their update: until you update Roleplay and Social, the group is empty.
- For app authors: `settingsView` in the manifest, and `window.molfarShell.onView(fn)` in the app. A name sent while the app is still opening waits for up to a minute. See the `app-authoring` skill.

## 💬 Social 0.5.0: the messenger remembers
- **A memory note per chat.** Messages that left the context window are folded into a short note by the messenger's model, so a long chat does not lose its story. You can read and edit the note in the chat's info card ("Memory and conversation…"). It can be switched off in Settings > Messenger ("Note of older messages").
- **New conversation** starts a fresh thread under a divider and keeps the note; **Clear chat** is a separate button with a confirmation that names how many messages go; it deletes the note too.
- **How well a character knows you** (knows you / only your name / a stranger): set per profile on the Voice tab, with a default for all profiles in Settings.
- **Out of character:** a message in double parentheses, like ((this)), or starting with OOC, is answered briefly and plainly, outside the story.

## 🎭 Roleplay 4.105.0
Opens its own Settings when you pick it in App settings. Nothing else changed.

## Known limits
- The memory note was tried with a fake model only. Please try it with your real model and report what reads wrong (#333).
- The forum does not use the note or "how well it knows you" yet.
- The settings guide pages are translated by a cheap model without a native read.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. Apps: Updates > Roleplay / Social > Update. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
