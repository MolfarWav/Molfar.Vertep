# 🧠 Molfar Vertep 1.11.1

A button that shows how big your requests are, an alarm for the ones that get too big, and a one-click way to carry on in a new chat. The engine itself is unchanged; everything arrives as **Roleplay 4.92.0, an app update**. **Order:** get this engine release and restart, then open Updates and press Update on Roleplay.

## 📏 Know the size of a request, and cut it before it costs
- **Request size button.** The chat header has a coloured button next to the story tools. It shows how many tokens the last request sent (the whole prompt, as the provider counted it) and which model got it. No more checking the provider's site. Press it for the model, its window and your limit. It is teal below three quarters of the limit, amber from there, red with a warning sign past it. On a phone it is a row in the chat Menu, and a chip in the header once the request is past the limit.
- **The alarm.** When a reply pushes the request past your limit, a popup opens: **Yes, continue in a new chat**, **Not now** (hides it for this chat until the request has grown by half), and, with Litopys on, **Send finished scenes as chapters instead**. An old chat that is already past the limit shows the red button and no popup.
- **Your limit.** Set it in the popup or in Library > Litopys settings > In the prompt > **Warn me when a request gets big**: 60% of the model's window (default), a size you type or pick (100k, 16k to 500k), or never. It counts the whole request, not only the memory.

## ➡️ Continue in a new chat, in one click
- From the popup or the chat's **More** menu. The new chat is created at once and opens; there is nothing to fill in. It keeps the old chat's preset and options, persona, model, agents (the set it follows, or its own copy), a group's turn order and its World DM world, and it is linked to the old chat the way the Canvas links chats, so the old story rides along as chapters and facts (up to three chats back). The old messages are not sent, so the prompt starts small.
- The New chat step also has a **Continues** menu with the character's earlier chats, for picking any of them.

## 🔥 What fired
- The Lore button in the header is now **Fired**. One panel says what went into the last reply, with tabs for Lorebooks, Litopys, the Data Bank and Vectors, for the last reply or the whole chat. Lorebooks also lists what was held back and why. Counts for the whole chat are approximate and start from this update.

## 📚 Docs
- A guide page, **Long chats and token cost**, and two Help articles about the Request size button and continuing a story. The translations of the new guide page arrive with the next refresh and show English until then.

## Known limits
- Tried in a browser with a fake model only: not with a real provider, not on Windows, not on a phone. Carrying a World DM world and a group's turn order was not run in a browser.
- The Request size button reads the usage the provider reports for the newest reply; a provider that reports none shows a dash.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
