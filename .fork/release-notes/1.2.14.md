# 🧾 Molfar Vertep 1.2.14

The Roleplay card editor saves when you say so, exported cards mark their Profile sections, and a card can choose the model for its own tasks. All of it is Roleplay 4.60.0, which comes as an app update; the engine itself does not change in this release.

### 💾 The card editor keeps a draft until you press Save (#103)
Until now every keystroke in a card was written at once, and a slip was fixed by hand or from Versions. Now:
- Edits in **any tab** wait in a draft. A bar at the bottom (above the keyboard on a phone) shows **Unsaved changes (N)** with **Discard** and **Save changes**; each tab that holds a change has an amber dot.
- **Save changes** writes the changed fields once. **Discard** puts every field back.
- **Leaving with unsaved changes asks first**: Save and leave, Discard and leave, or Keep editing. It covers the back arrow, another section or card, a chat, the phone's back gesture and a page reload.
- If the card changed while you were editing (Molfar, sync, another tab), Save shows which fields differ and lets you keep yours or take the stored version. The rest is saved either way.
- Export and Duplicate work on the saved card and ask whether to save first. Translate waits until the changes are saved or discarded. The favourite star, the card kind and the Soul tab stay immediate actions of their own.

### 🏷️ Profile sections are marked in exported cards (#105)
A card with a Profile exported to PNG, CHARX or JSON now carries a heading before each section's lines in `description` and `personality` (`## Identity`, `## Appearance`, `## Behaviors`, `## Goals`…), so SillyTavern and other apps show where a line comes from. The Export menu has a **Mark the profile sections** switch (on by default). Your card keeps its plain text. Importing such a file here takes the headings out again and rebuilds the Profile if the file lost it; a card that merely uses headings like these is left alone.

### 🧠 A model for the card's own tasks (#104)
Structure it, Fill empty and the Soul rating used the Dashboard sensor's model, a cheap one picked for short JSON. Now the Profile tab has **Model for this card's tasks**, and Settings has a new **Card tasks** section for an app-wide choice. The order is: this card, the app-wide model, the Dashboard sensor, the app default. The panel shows the model's window and reply size, the card's size and whether it fits in one call; the reply limit follows the model's real maximum, and the sizes can be set by hand. A card too long for one call is **read in parts and merged** instead of being cut. The choice is saved with Save changes, beside the card (not inside it), so a shared card carries none. Translation and Read from picture keep their own models.

## Other changes
- The phone's back gesture can now be refused by a screen that has unsaved changes.
- Structure it and Fill empty read the text on screen, not only the saved card.
- Not done and tracked: unmatched lines in a marked file do not go to notes (the import only rebuilds a Profile that reads back exactly); the memory plan (#102) is next.

## How to get it
Roleplay 4.60.0 comes as an app update (Apps → Updates). From source: `Molfar-Vertep.bat` picks up the new release. Downloads: the archives and the Android APK on this release page. Full list: [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md).
