# 🧠 Molfar Vertep 1.11.5

A fixes release. The engine gets four small changes, and **Roleplay 4.96.0 arrives as an app update** with three memory and helper fixes.

## 🔄 After a Sync pull, open apps refresh themselves
- When a pull brings new files into an app's data (for example a preset made on another device), the engine now tells the open app to re-read its data. Before, this relied only on the file watcher, which may not run on every device, so a pulled preset could stay hidden until a manual reload.
- The server log also lists what a push or pull moved, grouped by area (for example `apps/roleplay/data/presets=1`), so a missing file can be traced to the push or to the pull.
- Not yet known: why one reported preset never reached the other devices. That report stays open until the reporter says whether the file exists on the first device's disk and what Settings > Sync > Check shows.

## ⚡ Reading from an app no longer queues a commit
- Every app route used to queue a workspace commit, even a plain read, and the status walk behind it slowed the next call when an app folder held a large `node_modules` (22,000 files here: a trivial read went from 18 to about 130 ms when calls came back to back). Now a route queues a commit only when it can have changed something (any write, or a read that wrote a file).
- One thing changes: an edit made outside a route (by the agent or the shell) is committed with the next writing route instead of the next read.

## 🔊 Edge voices work with a wrong PC clock on older Bun
- If the clock is off by more than a few minutes, the Edge read-aloud service refuses the connection and the engine retries with the server's time. On Bun 1.4.0 the refusal arrived without its `Date` header, so the retry never happened and you got a bare 403. The engine now reads the time with a plain request when the header is missing. Not tried on Bun 1.4.0 itself, only with a simulated missing header.

## 🧠 Roleplay 4.96.0 (app update)
- **Helper models see names, not `{{user}}`.** The calls that write the story record, the Dashboard, the World builder and Dungeon Master, letters and the Agents plugin now receive your persona's name (and the character's name in a one-character chat) instead of the literal macros. Stored text keeps its macros.
- **A chat with Litopys switched off on the Prompt board stops spending model calls** on chapters, arcs, summaries and vectors until you switch it on again.
- **The room reserved for memory inserts is right for a normal chat whose card names several characters** ("who knows what" and "hidden plan" were reserved only in groups).
- Update it with **Update** on Roleplay in Updates.

## 🛠️ Fixes
- A flaky timing test (the request pacer) now uses a monotonic clock.

## Other changes
- Tests: the prompt cut line is checked after a message is deleted above it, the message it points at, and below it.
- Known and left: a chat with no card still gets the "who knows what" insert without reserved room; the "recollections" reserve is one reply late; in "fit" mode Litopys may add chapters for messages the engine kept in the prompt (not reproduced).

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart, then Update on Roleplay in Updates. `dev` only updates the engine, not the Roleplay app. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
