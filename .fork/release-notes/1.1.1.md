# 🔄 Molfar Vertep 1.1.1

A small fix for sync between devices, found on the first day of real use.

## 🛠️ Fixes
- **A push could land in the Google Drive trash** (#45). If the sync folder on Google Drive was moved to the trash, a device that was still connected to it pushed into the trash and said all was well. Now check, push and pull stop with "the sync folder is in the Google Drive trash": restore the folder, or press **Disconnect** and sign in with Google again to start a new one.
- **A refused push showed nothing** (#45). When the sync already held another device's push, pressing **Push** was refused, but the message vanished at once. It now stays on screen.
- **Clearer words on a new device** (#45). A device that never synced before now reads "This sync already holds {device}'s files. Pull first." instead of a warning that sounded as if it had synced before.
