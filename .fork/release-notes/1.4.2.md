# 🎨 Molfar Vertep 1.4.2

Two Roleplay app updates ride with this release: coloured voices that work in Russian and Ukrainian chats, and a greeting that follows the persona you pick. The engine itself has no code change.

### 🎭 Voices work with dashes and in other scripts
You can test it on a Narrator card that lists voices under Colors > Voices. Before, the colours only worked for speech in quotation marks and for names written the way the card spells them. Now:
- Dialogue set off by a dash (`— Hello`) is coloured like quoted speech, in every chat. The author's words between two dashes (`— No, — she said. — Go.`) stay plain.
- A voice is found when the story writes its name in the other script: the voice `Ember` is found as `Эмбер`, `Isabella Falafel` as `Изабелла`.
- A speech paragraph that names nobody (a pronoun only) takes the speaker of the narration paragraph right before it. A paragraph with speech never hands its speaker on, so a reply by someone else is not painted with the wrong colour.
- Vertep Lite now asks the model to name the speaker by name, not only "he" or "she", in the same paragraph as each line.

### 🎬 A fuller scene on the Dashboard
A small sensor model can leave people out of the scene state. A rated character (one with a soul) whom the story names at least twice in the new reply now joins the scene even then, by first name, alias or the other script, unless the sensor says they left. Before, only people who were already in the scene were kept.

### 🧑 A greeting follows the persona
Changing the persona of a chat before the first reply now changes `{{user}}` in the greeting, for a character chat and for the openings of a group chat. Before, only a swipe fixed it.

Open Updates and press Update on Roleplay.

## Other changes
- The chat's saved dashboard states are not rewritten: the fuller cast shows from the next state update.
- Vertep Lite changes in the preset template only; a copy you made keeps its own text.

## How to get it
From source: `git pull && bun install && (cd client-agent && bun install) && bun run build:client`, then restart. Downloads and the Android APK are on this release page. See [CHANGELOG.md](https://github.com/MolfarWav/Molfar.Vertep/blob/main/CHANGELOG.md) for details.
