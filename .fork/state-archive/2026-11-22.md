## 2026-11-22: #493 Social forum: characters never opened new topics (Social branch `claude/forum-new-topics-493`, commit 7fdf4f5, from main 779388b, merged and released in 0.22.2)
- Cause (read on the owner's real data, nothing written): `planAction` answered owed, invitations and mentions first and rolled `newTopicShare` only when none waited; with 54 profiles 3 authors had an invitation and 8 had 37 mentions, so the roll was never reached (1440 asked plans: 0 new topics); no character opened a topic since 2026-11-10, and the two boards added later had none.
- Fix: the new-topic roll comes before invitations and mentions (what is owed to the user stays first), forced only when nothing at all can be answered; a board with few topics weighs more (`1 + 3 / (1 + n)`); a name counts as a mention only when it starts a word (`remember` was a mention of Ember; an ending still counts, `Марку`). Same asked plans on the fixed plugin: 278 of 1440 new topics (19%), 131 of them on the two new boards. Not changed: favourites still limit the board choice (idea 4 of the issue).
- Tests: 3 new in `test/forum-plugin.test.ts` (they fail on the old code); full Social suite 698 pass, tsc clean. Not run with a real model; Social not released (CHANGELOG "Unreleased"; a release needs the version bump, guide translations and the merge, owner's word).
