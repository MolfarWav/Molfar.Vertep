# First steps

How to get from nothing to your first chat. Read this once, in order.

## 1. Install and start

Download the file for your system from the releases page on GitHub, unpack it and start it. Windows, macOS, Linux, Android and Docker are supported. The release page says which file to take. When it starts, your browser opens a one-time setup page. If it does not, the link is printed in the window where Molfar Vertep started.

## 2. Create your account

On the setup page, create the first account. It is local and never leaves your machine. This first account is the administrator and can add other people later in Settings, Users. Each person gets a separate workspace.

## 3. Connect a model

Nothing answers without a model, so the start page tour begins here. Open Settings (the gear; on a phone, the account menu at the top right), then "Connections and models", then "Add connection". Pick a provider and paste its API key. You can also choose "Subscriptions (OAuth)" to sign in instead of pasting a key, "Local model" for something running on your computer, or "Custom endpoint" for any OpenAI-compatible server.

A connection shows "Connected" once it has a key. That only means a key is saved, not that the model works. See [[models]].

## 4. Install and open Roleplay

On a first start, a welcome screen offers the official apps with Roleplay ticked. Press "Install"; the first app that installs opens. If you skipped it, open "Store" on the start page and install Roleplay there. Afterwards, click it on the start page and press "Launch" (on a phone, a tap opens it).

## 5. Start your first chat

Inside Roleplay, pick a character and start a chat. How cards, personas and chats work is in the Roleplay guide: [[roleplay:index]].

## Where to ask Molfar

Open his tab with the "Molfar" row on the start page. Ask for anything about your apps: "make the chat text bigger", "create a character called ...". If you are not sure what to do next, ask him that too. See [[molfar]].
