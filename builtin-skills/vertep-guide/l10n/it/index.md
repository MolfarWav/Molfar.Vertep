# Guida di Molfar Vertep

Molfar Vertep è un programma che gira sul tuo computer o telefono e si apre nel browser. Ospita app, di cui **Roleplay** è la principale: lunghe chat con personaggi AI. Porti tu il modello AI (una chiave API, un accesso in abbonamento o un modello sulla tua macchina). Dentro vive **Molfar**, un agente integrato che modifica le app per te quando glielo chiedi con parole semplici.

Le tue chat, i personaggi e le chiavi restano in file sul tuo disco. Nulla lascia la macchina tranne le chiamate al modello che hai collegato.

Questa guida è la panoramica: cos'è ogni parte e come le parti si incastrano. Ogni app ha anche il proprio Aiuto per le sue schermate.
