# ヘルプとバグ報告

Molfar Vertep の中で答えを探す場所と、何かが壊れたときの対処。

## ヘルプ

アカウントメニュー（右上）の「ヘルプ」は、短い答えを検索できる一覧です。各回答には「場所を見る」ボタンがあり、画面上のその場所へ連れて行ってくれます。エージェントページには、その画面専用のヘルプボタンもあります。パソコンではヘッダー、スマホではサイドバーにあります。

## ツアーと新機能

画面を初めて開くと短いツアーが始まります。「新機能」はアップデート後に現れ、新しい機能を案内します。設定の一般、ガイドでは、ツアーをオフにしたり、もう一度再生したり、新機能をもう一度表示したりできます。

## Molfar に聞く

自分の環境についての質問は、Molfar のタブで聞いてください。アプリが失敗したとき、エラーバーにある「Molfar に聞く」ボタンが、新しいチャットで問題を彼に送ります。[[molfar]]を参照。

## バグを報告

「バグを報告」はアカウントメニューにあり、スタートページの下部、Discord リンクの隣にもあります。次の手順で動きます。

1. 何が起きたかを書きます。直前にした操作と、エラーの正確な文言。
2. デバイスとブラウザーの行を確認します。スマホやパソコンの機種を足すと助かります。
3. スクリーンショットを撮ります。パソコンではブラウザーがどのウィンドウまたはタブを撮るか尋ねます。スマホでは自分で撮って後で添付します。
4. 「GitHub で開く」で記入済みの issue を開くか（無料の GitHub アカウントが必要）、「Discord 用にコピー」で Discord に貼り付けます。

バージョン、画面サイズ、最新のエラーが報告に含まれます。フォーム自体からは何も送信されません。自分で読んでから、自分で送ります。

## まず Molfar に聞く

同じフォームの「まず Molfar に聞く」ブロックは、説明を GitHub ではなく Molfar に渡します。新しいチャットを開き、テキストとデバイス詳細、最新のエラー、アプリ名を送ります。これらは Molfar と、あなたが接続したモデルにだけ送られます。

彼は原因を探し、あなたのコピーで修正を試みます。あなたがテストします。うまくいけば「動いた、修正を送る」カードから編集できるフォームが開き、GitHub に送るのはあなたが提出したときだけです。まだ壊れていれば「まだ壊れている」が Molfar に伝えます。原因が Molfar Vertep 本体にある場合は彼には直せず、カードに「GitHub で報告」が出ます。
