# Molfar Vertep ガイド

Molfar Vertep は、自分のパソコンやスマホで動き、ブラウザーで開くプログラムです。アプリをホストし、その主役が **Roleplay** です。AI キャラクターとの長いチャットができます。AI モデルは自分で用意します（API キー、サブスクリプションのサインイン、または自分のマシン上のモデル）。中には **Molfar** がいます。内蔵エージェントで、平易な言葉で頼むとアプリを変更してくれます。

チャット、キャラクター、キーは自分のディスク上のファイルに残ります。接続したモデルへの呼び出し以外は、マシンから出ません。

このガイドは概要です。各部分が何で、どう噛み合うのか。各アプリにも、その画面専用のヘルプがあります。
