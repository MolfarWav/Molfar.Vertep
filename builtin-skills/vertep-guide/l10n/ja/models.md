# モデルと接続

Molfar とアプリが答えるには AI モデルが必要です。このページでは、接続方法、表示するモデルの選択、画像と音声の設定を説明します。すべて設定の中にあります。

## 接続

接続はプロバイダーやサーバーへの保存済みリンクです。設定を開き、「接続とモデル」、「接続を追加」の順に進みます。プロバイダーの一覧には以下があります。

- 有名プロバイダー：選んで API キーを貼り付けます。
- 「サブスクリプション（OAuth）」：キーの代わりにサインインします。
- 「ローカルモデル」：自分のパソコンで動く Ollama、LM Studio、llama.cpp など。
- 「カスタムエンドポイント」：OpenAI 互換など、対応形式を話す任意のサーバー。

キーが入ると（または不要なら）接続は「接続済み」、そうでなければ「キーが必要」と表示されます。これはモデルが動く確認ではありません。キーはこのパソコンにだけ保存されます。

## 表示するモデルの選択

1つの接続で何百ものモデルが得られることがあります。接続の下の一覧では：

- 選択肢に表示したいモデルにチェックを付けます。何もチェックがなければ全部表示されます。
- 切り替えるモデルに星を付けます。これが「クイック切り替え」になり、Molfar のチャットやアプリのモデル選択で先頭に来ます。
- スライダーアイコンでモデル独自の設定を開きます。

## モデル別設定

モデル設定には、コンテキストウィンドウ、最大出力トークン、推論、価格（100万トークンあたりのドル）、プロンプトキャッシュの確認、キャッシュの寿命、ペナルティや Min P などのサンプリングパラメータが含まれます。「キャッシュを確認」は、プロバイダーが繰り返しのプロンプトをキャッシュから読むかどうかを示します。これはより安く、速くなります。キャッシュの寿命には3つの選択肢があります。「プロバイダー自身」（通常約5分、余分なものは送信されません）、「Long」（Claude では1時間、GPT では最大1日を要求します。余分なリクエストはありませんが、キャッシュの書き込みはより高くつきます。対応する接続でのみ提供されます。Anthropic 自体、OpenRouter 経由の Claude、OpenAI で、それ以外ではグレーアウトします。ゲートウェイがそれを無視したり、リクエストを拒否する可能性があるためです）、「Keep alive」（チャットの返答後、エンジンはキャッシュが失効しないように最大40分間、約5分ごとに小さなリクエストを送ります。毎回プロンプトの入力価格の約10分の1のコストがかかり、リクエスト制限とサブスクリプションに計上され、モデルの価格が設定されている必要があり、ツールや Claude の思考とは併用されません（Claude の思考を含むリクエストは、keep-alive リクエストが持つ16トークンより大きな回答を必要とします）。チャットには何も書き込まず、パネルはリクエストを数え、実行されていないときはパネルが理由を表示します）。Anthropic または OpenRouter の Claude には「Long」から始めてください。余分なリクエストは不要です。NanoGPT などのゲートウェイ経由の Claude は長い寿命を無視し、そこの Gemini モデルは数分間自分でキャッシュします。それらには Keep alive を使ってください。Roleplay では、チャットヘッダーの Request size ボタンが、最後のリクエストのどれだけがキャッシュから来たか、プロンプトのどこでキャッシュが終わるかを示します。Keep alive は長いオプションがないプロバイダー向けで、1日のリクエスト制限がある無料モデル向けではありません。「推奨設定」で妥当な値を入れられ、「元に戻す」で戻ります。Molfar、アプリのチャット返答、個別プラグインに別々のブロックを適用できます。オフにした欄は送信されません。

## 画像モデル

アプリはこのモデルに画像を送ります。たとえば肖像からキャラクターを説明するときです。「自動」は画像を読める最も安いモデルを使います。どれも読めなければ、対応モデルのある接続を追加してください。

## 画像

設定の「画像」で、すべてのアプリの画像生成を設定します。接続から画像モデルを追加するか、画像サーバーを追加します。API をオンにして起動した ComfyUI、AUTOMATIC1111、Forge サーバー、または images エンドポイントのある任意のサービスです。ComfyUI は RunPod Serverless 上のものにもできます。ComfyUI を選び、アドレスとして `https://api.runpod.ai/v2/` に続けてエンドポイント ID を入力し、キーには RunPod の API キー、「モデル」にはワーカー上のチェックポイントのファイル名を入力します（RunPod は一覧を取得できません）。「確認」でエンドポイント ID とキーが正しいか分かります。ワーカーの起動中、最初の画像には最大 30 秒ほどかかることがあります。星を付けた画像モデルはお気に入りになります。Molfar が用途に応じて選び、Roleplay は自分の選択欄でこれらを先頭に表示します。

## 音声

「音声」はすべてのアプリに読み上げを提供します。無料の Edge 音声はすぐ使え、それぞれに「テスト」ボタンがあります。「エンドポイントを追加」で音声サービス（OpenAI、Groq、ローカルサーバー）をモデル名、既定の音声、キー付きで追加できます。

## コストと小さなモデル

- Molfar は大きなタスクや有料の画像の前にコスト見積もりを表示します。設定の Molfar にある「コスト確認」を参照。
- コンテキストウィンドウが小さいモデルは、Molfar の完全な指示では溺れることがあります。「小型モデルモード」は短いプロンプトを送ります。既定の「自動」は32kトークン以下、またはサイズ不明のときにオンになります。
