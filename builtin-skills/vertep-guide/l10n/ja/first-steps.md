# はじめの一歩

何もない状態から最初のチャットまで。最初に一度、順番に読んでください。

## 1. インストールと起動

GitHub のリリースページから、お使いのシステム用のファイルをダウンロードし、展開して起動します。Windows、macOS、Linux、Android、Docker に対応しています。どのファイルを選ぶかはリリースページに書かれています。起動すると、ブラウザーで1回限りのセットアップページが開きます。開かなければ、Molfar Vertep を起動したウィンドウにリンクが表示されています。

## 2. アカウントを作る

セットアップページで最初のアカウントを作ります。アカウントはローカルにあり、あなたのマシンから出ません。この最初のアカウントが管理者になり、後から設定のユーザーで他の人を追加できます。人ごとに別々のワークスペースが与えられます。

## 3. モデルを接続する

モデルがないと誰も答えません。スタートページのツアーはここから始まります。設定（歯車。スマホでは右上のアカウントメニュー）を開き、「接続とモデル」、そして「接続を追加」です。プロバイダーを選び、API キーを貼り付けます。キーの代わりにサインインする「サブスクリプション（OAuth）」、自分のパソコンで動くモデル用の「ローカルモデル」、OpenAI 互換サーバー用の「カスタムエンドポイント」も選べます。

キーが入ると接続は「接続済み」と表示されます。これはキーが保存されただけで、モデルが動く確認ではありません。[[models]]を参照。

## 4. Roleplay をインストールして開く

初回起動時はウェルカム画面に公式アプリが出て、Roleplay にチェックが付いています。「インストール」を押すと、最初にインストールされたアプリが開きます。スキップした場合は、スタートページの「ストア」を開いて Roleplay をインストールしてください。その後、スタートページでクリックして「開く」を押します（スマホはタップで開きます）。

## 5. 最初のチャットを始める

Roleplay の中でキャラクターを選び、チャットを始めます。カード、ペルソナ、チャットの仕組みは Roleplay ガイドにあります：[[roleplay:index]]。

## Molfar に聞く場所

スタートページの「Molfar」の行で彼のタブが開きます。アプリについて何でも聞けます。「チャットの文字を大きくして」「…というキャラクターを作って」。次に何をすればいいか分からないときも、それを聞いてください。[[molfar]]を参照。

## 次のおすすめ

- スマホや別のパソコンへの移行：[[devices]]。
- 分からない言葉：[[glossary]]。
