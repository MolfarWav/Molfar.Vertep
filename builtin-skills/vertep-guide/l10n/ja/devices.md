# デバイス、同期、バックアップ

スマホでの Molfar Vertep の使い方、デバイス間での物語の持ち運び、アプリとしてのインストール、新しいパソコンへの移行。

## スマホから開く

設定のサーバーで「同じネットワークの他のデバイスを許可」すると、同じネットワーク上のスマホや別のパソコンから Molfar Vertep を開けます。QR コードにアドレスが表示されるので、スマホのカメラで読み取ってください。各アカウントには引き続きパスワードが必要です。スマホではマイクとアプリ化に HTTPS が必要なので、その場合は同じセクションで「HTTPS を使う」をオンにします。これらの項目は管理者だけが見られます。

## アプリとしてインストール

アカウントメニューの「アプリをインストール」で、Molfar Vertep がホーム画面やパソコンのアプリ一覧に追加されます。以降はブラウザのバーなしで専用ウィンドウで開きます。iPhone では Safari の保存場所が表示されます。共有から「ホーム画面に追加」です。http アドレスでパソコンを開いているスマホは、先に https が必要です。ダイアログに方法が表示されます。開いているアプリには「全画面」もあり、専用のブラウザタブで開いてインストールできます。

## 同期

アカウントメニューの「デバイスを同期」、または設定の「同期」。各デバイスで一度 Google にサインインします。遊び終えたら「Push」を押し、別のデバイスで「Pull」を押して続けます。2回目以降は変更分だけが移動します。

- 移動するものを選べます。アプリとそのデータ、Molfar のチャットとプロジェクト、画像・音声・動画、API キーと MCP 設定。キーはオンにした場合のみ、各デバイスで入力するパスフレーズでロックされて移動します。
- 同じチャットが両方で変更された場合は、どちらの版を残すか選びます。もう一方は30日間保存されます。
- 同期フォルダ（Syncthing、デスクトップ版 Google Drive）や USB メモリ用の「フォルダ」もあります。

## バックアップ

設定のバックアップは、プロフィール全体を書き出します。アプリとそのデータ、Molfar のメモリーとチャットです。「プロフィールをエクスポート」を押してください。パスワードを付けると API キーも暗号化して含まれます。ない場合はキーなしのバックアップになり、再度入力します。インポートは先に中身を表示します。「プロフィールを置き換える」を押すと、現在のプロフィールを保存してから置き換えます。

新しいパソコンへの一度の移行にはバックアップを、頻繁な往復には同期を使います。
