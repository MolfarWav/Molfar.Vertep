# Erste Schritte

So kommst du vom Nichts zu deinem ersten Chat. Lies das einmal in dieser Reihenfolge.

## 1. Installieren und starten

Lade auf der Release-Seite auf GitHub die Datei für dein System herunter, entpacke sie und starte sie. Unterstützt werden Windows, macOS, Linux, Android und Docker. Die Release-Seite sagt, welche Datei du nehmen sollst. Beim Start öffnet dein Browser eine einmalige Einrichtungsseite. Falls nicht, steht der Link in dem Fenster, in dem Molfar Vertep gestartet wurde.

## 2. Konto erstellen

Erstelle auf der Einrichtungsseite das erste Konto. Es ist lokal und verlässt deinen Rechner nie. Dieses erste Konto ist der Administrator und kann später unter Einstellungen, Benutzer weitere Personen hinzufügen. Jede Person bekommt einen eigenen Arbeitsbereich.

## 3. Ein Modell verbinden

Ohne Modell antwortet nichts, deshalb beginnt die Einführung auf der Startseite hier. Öffne Einstellungen (das Zahnrad; auf dem Handy das Kontomenü oben rechts), dann „Verbindungen und Modelle“, dann „Verbindung hinzufügen“. Wähle einen Anbieter und füge seinen API-Schlüssel ein. Du kannst auch „Abos (OAuth)“ wählen, um dich anzumelden statt einen Schlüssel einzufügen, „Lokales Modell“ für etwas, das auf deinem Computer läuft, oder „Benutzerdefinierter Endpunkt“ für jeden OpenAI-kompatiblen Server.

Eine Verbindung zeigt „Verbunden“, sobald sie einen Schlüssel hat. Das heißt nur, dass ein Schlüssel gespeichert ist, nicht dass das Modell funktioniert. Siehe [[models]].

## 4. Roleplay installieren und öffnen

Beim ersten Start bietet ein Willkommensbildschirm die offiziellen Apps an, mit Roleplay angehakt. Drücke „Installieren“; die erste installierte App öffnet sich. Falls du das übersprungen hast, öffne auf der Startseite „Store“ und installiere Roleplay dort. Danach klicke es auf der Startseite an und drücke „Starten“ (auf dem Handy öffnet ein Tippen die App).

## 5. Deinen ersten Chat beginnen

Wähle in Roleplay einen Charakter und beginne einen Chat. Wie Karten, Personas und Chats funktionieren, steht im Roleplay-Leitfaden: [[roleplay:index]].

## Wo du Molfar fragst

Öffne seinen Tab über die Zeile „Molfar“ auf der Startseite. Frag ihn alles über deine Apps: „mach den Chat-Text größer“, „erstell einen Charakter namens …“. Wenn du nicht sicher bist, was als Nächstes zu tun ist, frag ihn auch das. Siehe [[molfar]].
