# 设备、同步与备份

如何在手机上使用 Molfar Vertep，在设备间转移你的故事，像应用一样安装它，以及迁移到新电脑。

## 从手机打开

在设置 > 服务器中，“允许我网络中的其他设备”允许同一网络中的手机或另一台电脑打开 Molfar Vertep。二维码会显示地址；用手机相机扫描即可。每个账户仍需要其密码。手机只允许麦克风和通过 HTTPS 安装为应用，因此对于这些功能，你需要在同一部分中开启“使用 HTTPS”。这些部分对管理员可见。

## 像应用一样安装

账户菜单中的“安装应用”会把 Molfar Vertep 放到你的主屏幕或电脑的应用列表中。之后它会在自己的窗口中打开，没有浏览器栏。在 iPhone 上，它会显示 Safari 保存它的位置：共享，然后添加到主屏幕。通过 http 地址打开你电脑的手机需要先使用 https，对话框会解释如何操作。打开的应用也有“全屏”，它会在其独立的浏览器标签页中打开，你可以安装它。

## 同步

账户菜单中的“同步设备”，或设置 > 同步。在每台设备上使用 Google 登录一次。当你停止游玩时，按“推送”；在另一台设备上按“拉取”，然后继续。首次之后，只传输更改的内容。

- 你选择传输的内容：应用及其数据、Molfar 的聊天和项目、图片、声音和视频，以及 API 密钥与 MCP 设置。只有在你开启它们并输入你在每台设备上设置的密码短语锁定时，密钥才会传输。
- 如果同一个聊天在两台设备上都有更改，你选择保留哪个版本。另一个版本会保存 30 天。
- 还有“文件夹”选项，用于同步文件夹（Syncthing、桌面版 Google Drive）或 U 盘。

## 备份

设置 > 备份会导出你的整个配置文件：应用及其数据、Molfar 的记忆和聊天。按“导出配置文件”。添加密码即可包含你的 API 密钥（加密）；不设密码的备份不含密钥，你需要重新输入。导入会先显示其中内容。当你按“替换我的配置文件”时，当前配置文件会先被保存，然后再被替换。

使用“备份”迁移到新电脑一次。使用“同步”频繁地来回传输。

## 仅一个应用

起始页上应用详情的“导出应用”会生成仅含该应用的备份文件。“导入应用”可导入此类文件。参见 [[apps]]。
