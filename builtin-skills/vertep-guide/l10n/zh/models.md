# 模型与连接

Molfar 和你的应用需要一个 AI 模型来回答。本页解释如何连接一个模型、选择显示哪些模型，以及设置图像和语音。这些都在设置中完成。

## 连接

连接是指向提供商或服务器的已保存链接。打开设置，然后进入“连接与模型”，再进入“添加连接”。提供商列表提供：

- 知名提供商：选择一个并粘贴其 API 密钥。
- “订阅（OAuth）”：你通过登录来代替粘贴密钥。
- “本地模型”：Ollama、LM Studio、llama.cpp 以及在你自己的电脑上运行的其他内容。
- “自定义端点”：任何使用受支持格式（例如兼容 OpenAI）的服务器。

连接在拥有密钥（或无需密钥）后会显示“已连接”，否则显示“需要密钥”。这并非模型正常工作的测试。密钥仅存储在这台电脑上。

## 选择显示哪些模型

一个连接可以带来数百个模型。在连接下方的列表中：

- 勾选选择器应显示的模型。如果没有勾选任何模型，则显示所有模型。
- 为你切换的模型加星标。这些模型构成“快速切换”，并在模型选择器、Molfar 的聊天和应用中排在前面。
- 使用滑块图标打开模型自身的设置。

## 按模型设置

模型的设置包括其上下文窗口、最大输出 token、推理、价格（美元/百万 token）、提示词缓存检查，以及采样参数，如惩罚项和 Min P。“推荐设置”可以填入合理的值，“还原”可以返回。单独的区块可以应用于 Molfar、应用中的聊天回复或单个插件。你留空的字段不会被发送。

## 视觉模型

应用会把图片发送给这个模型，例如根据肖像描述角色。“自动”会选择能读图的最便宜的模型。如果你的模型都不能读图，请添加一个包含此类模型的连接。

## 图像

设置中的“图像”为每个应用设置图像生成。你可以从你的连接中添加图像模型，或添加图像服务器：使用 API 启动的 ComfyUI、AUTOMATIC1111 或 Forge 服务器，或任何带有图像端点的服务。加星标的图像模型会成为收藏。Molfar 会按各模型的用途从中挑选，Roleplay 会在其选择器中把它们排在前面。

## 语音

“语音”为每个应用提供文本转语音。免费的 Edge 语音开箱即用；每个都有一个“测试”按钮。你还可以“添加端点”以使用语音服务（OpenAI、Groq 或本地服务器），并填写模型名称、默认语音和密钥。

## 成本与小模型

- Molfar 会在大型任务和付费图片之前显示成本估算。请参阅设置 > Molfar 中的“费用确认”。
- 上下文窗口较小的模型可能会被 Molfar 的完整指令淹没。“小模型模式”会发送更短的提示词。其默认值“自动”在 32k token 或更少时（或大小未知时）开启。
