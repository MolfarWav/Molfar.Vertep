# 模型与连接

Molfar 和你的应用需要一个 AI 模型来回答。本页解释如何连接一个模型、选择显示哪些模型，以及设置图像和语音。这些都在设置中完成。

## 连接

连接是指向提供商或服务器的已保存链接。打开设置，然后进入“连接与模型”，再进入“添加连接”。提供商列表提供：

- 知名提供商：选择一个并粘贴其 API 密钥。
- “订阅（OAuth）”：你通过登录来代替粘贴密钥。
- “本地模型”：Ollama、LM Studio、llama.cpp 以及在你自己的电脑上运行的其他内容。
- “自定义端点”：任何使用受支持格式（例如兼容 OpenAI）的服务器。

连接在拥有密钥（或无需密钥）后会显示“已连接”，否则显示“需要密钥”。这并非模型正常工作的测试。密钥仅存储在这台电脑上。

## 选择显示哪些模型

一个连接可以带来数百个模型。在连接下方的列表中：

- 勾选选择器应显示的模型。如果没有勾选任何模型，则显示所有模型。
- 为你切换的模型加星标。这些模型构成“快速切换”，并在模型选择器、Molfar 的聊天和应用中排在前面。
- 使用滑块图标打开模型自身的设置。

## 按模型设置

模型的设置包括其上下文窗口、最大输出 token、推理、价格（美元/百万 token）、提示词缓存检查、缓存生存时间，以及采样参数，如惩罚项和 Min P。“检查缓存”会告诉你提供商是否从缓存中读取重复的提示词，这样更便宜也更快。缓存生存时间有三个选项：“提供商自己的”（通常约 5 分钟，不会额外发送任何内容）、“Long”（向 Claude 请求一小时，向 GPT 请求最长一天；没有额外请求，写入缓存费用更高；仅在支持它的连接上提供：Anthropic 本身、通过 OpenRouter 和 OpenAI 使用的 Claude，在其他地方则置灰，因为网关可能会忽略它或拒绝该请求）和“Keep alive”（在聊天回复后，引擎大约每 5 分钟发送一个小请求，持续最长 40 分钟，以免缓存失效；每次的费用约为提示词输入价格的十分之一，会占用请求限制和订阅额度，需要设置模型的价格，并且不用于工具，也不用于 Claude 的思考（Claude 的思考请求需要比 keep-alive 请求的 16 token 更大的回答）；它不会向聊天写入任何内容，面板会统计这些请求，未运行时面板会说明原因）。对于 Anthropic 或 OpenRouter 上的 Claude，请从“Long”开始：它不需要额外请求。通过 NanoGPT 等网关使用的 Claude 会忽略长生存时间，而那里的 Gemini 模型会自行缓存几分钟：对这些模型请使用 Keep alive。在 Roleplay 中，聊天标题栏中的 Request size 按钮会显示上一次请求有多少来自缓存，以及缓存在提示词中的结束位置。Keep alive 适用于没有长选项的提供商，不适用于有每日请求限制的免费模型。“推荐设置”可以填入合理的值，“还原”可以返回。单独的区块可以应用于 Molfar、应用中的聊天回复或单个插件。你留空的字段不会被发送。

## 视觉模型

应用会把图片发送给这个模型，例如根据肖像描述角色。“自动”会选择能读图的最便宜的模型。如果你的模型都不能读图，请添加一个包含此类模型的连接。

## 图像

设置中的“图像”为每个应用设置图像生成。你可以从你的连接中添加图像模型，或添加图像服务器：使用 API 启动的 ComfyUI、AUTOMATIC1111 或 Forge 服务器，或任何带有图像端点的服务。ComfyUI 也可以是 RunPod Serverless 上的服务：选择 ComfyUI，地址填写 `https://api.runpod.ai/v2/` 加上你的端点 ID，密钥填写你的 RunPod API 密钥，并在“模型”下填写 worker 上的检查点文件名（RunPod 无法列出它们）；“检查”会告诉你端点 ID 和密钥是否正确。worker 启动期间，第一张图片可能需要最多约半分钟。 加星标的图像模型会成为收藏。Molfar 会按各模型的用途从中挑选，Roleplay 会在其选择器中把它们排在前面。

## 语音

“语音”为每个应用提供文本转语音。免费的 Edge 语音开箱即用；每个都有一个“测试”按钮。你还可以“添加端点”以使用语音服务（OpenAI、Groq 或本地服务器），并填写模型名称、默认语音和密钥。

## 成本与小模型

- Molfar 会在大型任务和付费图片之前显示成本估算。请参阅设置 > Molfar 中的“费用确认”。
- 上下文窗口较小的模型可能会被 Molfar 的完整指令淹没。“小模型模式”会发送更短的提示词。其默认值“自动”在 32k token 或更少时（或大小未知时）开启。
