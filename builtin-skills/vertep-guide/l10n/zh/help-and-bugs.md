# 帮助与错误报告

在 Molfar Vertep 内部哪里可以找到答案，以及当出现问题时该怎么做。

## 帮助

账户菜单（右上角）中的“帮助”是一个可搜索的简短答案列表。每个答案都有一个“带我去看”按钮，会带你到屏幕上的对应位置。智能体页面有自己的帮助按钮，用于其界面：在电脑上是页眉，在手机上是侧边栏。

## 导览与新功能

首次打开某个界面时，会启动一个简短的导览。更新后会出现“新功能”，指出新特性。在设置 > 通用 > 向导中，你可以关闭导览、重新播放它们，或再次显示新功能。

## 询问 Molfar

关于你自己的设置问题，请在他的标签页中询问 Molfar。当应用失败时，其错误栏会有一个“询问 Molfar”按钮，会在新聊天中把问题发送给他。参见 [[molfar]]。

## 报告错误

“报告错误”位于账户菜单中，也位于起始页底部 Discord 链接旁边。它的运作步骤如下：

1. 描述发生了什么：你之前做了什么，以及任何错误的原文。
2. 检查设备和浏览器行。添加你的手机或电脑型号会有所帮助。
3. 截取屏幕。在电脑上，你的浏览器会询问要捕获哪个窗口或标签页；在手机上，请自行截图，稍后附加。
4. 打开“在 GitHub 上打开”以获取预填的问题（需要免费的 GitHub 账户），或选择“复制到 Discord”将文本粘贴到 Discord。

版本、屏幕尺寸和最近的错误会随报告一起提供。表单本身不会发送任何内容：你首先阅读它，然后自行发送。

## 先问问 Molfar

同一表单中的“先问问 Molfar”块会把你的描述交给 Molfar，而不是 GitHub。它会打开一个新聊天并发送文本，同时附带你的设备详情、最近的错误和应用名称。这些内容只会发送给 Molfar 以及你连接的模型。

他会查找原因，并尝试在你应用副本中修复，然后你进行测试。如果有效，会有一张“有效，发送修复”的卡片打开一个你可以编辑的表单，修复只会在你在 GitHub 上提交时发送到那里。如果仍然损坏，“仍然损坏”会将其发送给 Molfar。如果原因在 Molfar Vertep 本身内部，他无法修复，卡片会提供“在 GitHub 上报告”。
