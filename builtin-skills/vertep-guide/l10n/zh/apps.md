# 应用

如何查找、添加、更新和移除应用。应用是你实际使用的东西：Roleplay 是主要的一个。

## 起始页

新标签页（+）会打开起始页“去哪里？”。它列出 Molfar 和你已安装的应用。在电脑上，点击一个应用可以查看其内部内容，然后按“打开”；详情里还有“导出应用”，以及针对有更新来源的应用提供的“检查更新”。在手机上，点按一下会立即打开它，（i）按钮显示详情。垃圾桶图标会在询问后删除应用，这会永久移除其数据。

每个打开的应用都有自己的标签页。标签页可以拖到任意顺序，并在刷新后恢复。

## 当应用打开时

工具栏提供：

- “分屏”：左侧为 Molfar，右侧实时显示应用。
- “全屏”：应用在独立的浏览器标签页中打开，你可以像安装应用一样安装它。
- “插件”：此应用的插件及其权限；从 git 导入更多。
- “重新构建”：立即重新构建此应用。

在手机上，这三项位于账户菜单中。

## 当应用想读取另一个应用时

应用可能会请求读取另一个应用的文件，例如 Social 读取你的 Roleplay 角色。第一次打开这类应用时，会出现一个问题：“允许 <app> 读取你的 <other app> 数据吗？”，并说明用途和具体文件。“允许”或“不允许”都是回答；“稍后决定”会在下次再次询问。这是只读权限：应用不能更改或删除另一个应用中的任何内容，只能看到列出的文件。你可以随时更改回答：在起始页打开该应用的详情，查看“其他应用的访问权限”。如果应用的更新需要更多文件，你会再次被询问。删除任一应用都会忘记该回答。

## 商店

起始页上的“商店”列出了来自 Molfar Vertep（标记为“官方应用”）和社区的应用。按“安装”：你首先会看到该应用包含哪些内容、可以访问什么，在你确认之前不会运行任何内容。只安装你信任的东西，因为应用会在你的电脑上运行真实代码。“刷新”会请求新应用，徽章会显示自你上次查看以来新增的应用数量。

## 新建和导入的应用

- “新建应用”：给它起个名字（作者可选），你会获得一个 Molfar 会与你一起完善的初始模板。
- “导入应用”：从 git 仓库或由“导出应用”生成的备份文件导入。它会先被检查，在你阅读其包含的内容并确认之前，不会运行任何内容。

## 更新

当有更新等待时，顶栏的下载图标会显示一个圆点。它列出了所有有更新来源的应用，并提供“立即检查”。从文件（zip）安装的应用会显示“没有更新来源”，无法在此更新。要获得更新，请从 Store 安装；该副本是独立的应用，因此如果它含有你想保留的数据，请先导出文件（垃圾桶图标会删除应用及其数据）。当两个或更多应用等待更新时会出现“全部更新”，它从不包括 Molfar Vertep 本身。

你自己的编辑会合并到更新中，你的数据会保留。如果你的编辑与新版本重叠，暂不会有任何更改：你可以选择“保留我的”、“接受更新”或“请 Molfar 合并”。安装新包或请求新权限的更新会等待你的确认。

## 应用设置在哪里

应用自身的设置在其内部。壳的“设置”中包含所有应用共享的内容：模型、语音、图像、记忆、MCP 服务器。参见 [[settings]]。

## 如果应用失败

当应用构建失败时，它会保留上一个良好版本，其错误栏会提供“询问 Molfar”，这会在新聊天中把问题发送给他。参见 [[help-and-bugs]]。
