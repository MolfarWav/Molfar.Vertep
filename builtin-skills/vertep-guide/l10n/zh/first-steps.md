# 第一步

如何从零开始，直到第一次聊天。按顺序完整阅读一遍。

## 1. 安装并启动

从 GitHub 的发布页面下载适合你系统的文件，解压并启动它。支持 Windows、macOS、Linux、Android 和 Docker。发布页面会告诉你该选择哪个文件。启动后，你的浏览器会打开一次性设置页面。如果没有，链接会打印在 Molfar Vertep 启动的窗口中。

## 2. 创建你的账户

在设置页面上，创建第一个账户。它是本地的，绝不会离开你的机器。这个第一个账户是管理员，之后可以在设置 > 用户中添加其他人。每个人都会获得独立的工作区。

## 3. 连接模型

没有模型就不会有回答，因此起始页导览从这里开始。打开设置（齿轮图标；在手机上，是右上角的账户菜单），然后进入“连接与模型”，再进入“添加连接”。选择一个提供商并粘贴其 API 密钥。你也可以选择“订阅（OAuth）”通过登录来代替粘贴密钥，选择“本地模型”使用在你电脑上运行的内容，或选择“自定义端点”使用任何兼容 OpenAI 的服务器。

连接在拥有密钥后会显示“已连接”。这仅表示密钥已保存，并不意味着模型可以正常工作。参见 [[models]]。

## 4. 安装并打开 Roleplay

首次启动时，欢迎屏幕会提供官方应用，Roleplay 已勾选。按“安装”；第一个安装的应用会打开。如果你跳过了，请在起始页打开“商店”，在那里安装 Roleplay。之后，在起始页点击它并按“打开”（在手机上，点按一下即可打开）。

## 5. 开始你的第一次聊天

在 Roleplay 内部，选择一个角色并开始聊天。关于卡片、人设和聊天如何工作的说明，请参阅 Roleplay 指南：[[roleplay:index]]。

## 在哪里询问 Molfar

使用起始页上的“Molfar”行打开他的标签页。可以询问任何关于你的应用的事情：“把聊天文本调大”、“创建一个叫……的角色”。如果你不确定下一步做什么，也可以问他。参见 [[molfar]]。
