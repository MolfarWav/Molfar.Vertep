# 词汇表

Molfar Vertep 中人们最容易混淆的词汇，每个词条都很简短。指南其余部分都严格按此含义使用它们。

## 程序

**Molfar Vertep** 是整个程序：你在电脑上启动并在浏览器中打开的东西。它包含你的账户、你的应用、你的模型连接和 Molfar。

**壳** 是围绕一切的框架：起始页、顶部的标签页、右上角的账户菜单以及设置对话框。它不是一个应用。当本指南说“设置”时，指的是壳的设置。

**起始页**（“去哪里？”）列出 Molfar 和你已安装的应用，并包含商店、新建应用和导入应用按钮。新标签页（+）会打开它。

## 应用和 Molfar

**应用** 是运行在 Molfar Vertep 内部的独立程序，拥有自己的界面和自己的数据。**Roleplay** 是主要的一个。每个打开的应用都位于自己的标签页中。你可以从商店、git 仓库或备份文件获取应用，或与 Molfar 一起构建你自己的应用。

**Molfar** 是内置的 AI 智能体。当你要求时，他会更改你的应用、角色卡、世界书、主题和设置文件。他是一个帮手，不是用来陪你玩的应用。

**智能体页面** 是 Molfar 的标签页：左侧是他的聊天记录，中间是对话。他标签页中的一切都与 Molfar 对话有关。

**与 Molfar 的聊天** 是智能体页面上的对话。它不是 Roleplay 聊天。Roleplay 聊天和你的角色一起，位于 Roleplay 应用内部。

**项目** 将与 Molfar 的聊天分组，并为它们提供共享的指令、记忆、技能和文件。每个已安装的应用本身就是一个项目，你也可以创建自由项目。它与 Roleplay 故事无关。参见 [[projects-and-chats]]。

## 你的文件

**你的工作区** 是属于你账户的文件夹：你的应用及其数据、Molfar 的记忆和技能、你的笔记和设置。Molfar 在其中编辑文件，始终在你可见的范围内。

## 模型

**连接** 是指向提供模型之处的已保存链接：带 API 密钥的提供商、订阅登录、本地服务器或你自己的地址。

**模型** 是 AI 本身，即撰写回复的东西。一个连接可以带来数百个模型。你在聊天中选择模型。参见 [[models]]。

## 附加内容

**插件** 是添加到应用中的一小段代码，通常用于赋予它新的后台能力。插件会列出它们请求的权限。

**技能** 是教 Molfar 一种工作类型的简短指令，例如你希望角色卡怎么写。他只在任务需要时加载技能。

**记忆** 是 Molfar 在聊天之间保留的内容：关于你和你工作的笔记。他会提出每条笔记，只有在你同意时才保存。不要与 Roleplay 内部属于应用的故事记忆混淆。
