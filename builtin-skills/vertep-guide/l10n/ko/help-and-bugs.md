# 도움말 및 버그 신고

Molfar Vertep 안에서 답을 찾는 곳과 문제가 생겼을 때 해야 할 일.

## 도움말

계정 메뉴(오른쪽 위)의 "도움말"은 검색 가능한 짧은 답변 목록입니다. 각 답변에는 "위치 보기" 버튼이 있어 화면의 해당 위치로 이동합니다. 에이전트 페이지에는 자체 화면을 위한 도움말 버튼이 있습니다. 컴퓨터에서는 헤더에, 휴대폰에서는 사이드바에 있습니다.

## 투어 및 새로운 기능

화면을 처음 열면 짧은 투어가 시작됩니다. "새로운 기능"은 업데이트 후에 나타나 새 기능을 알려줍니다. 설정, 일반, 가이드에서 투어를 끄거나 다시 재생하거나 새로운 기능을 다시 표시할 수 있습니다.

## Molfar에게 묻기

내 설정에 관한 질문은 Molfar의 탭에서 Molfar에게 물어보세요. 앱이 실패하면 오류 표시줄의 "Molfar에게 묻기" 버튼이 새 채팅으로 문제를 그에게 보냅니다. [[molfar]]를 참조하세요.

## 버그 신고

"버그 신고"는 계정 메뉴와 시작 페이지 하단의 Discord 링크 옆에 있습니다. 단계별로 작동합니다:

1. 무슨 일이 있었는지 설명하세요. 직전에 한 작업과 오류 메시지의 정확한 문구를 적습니다.
2. 기기 및 브라우저 줄을 확인하세요. 휴대폰이나 컴퓨터 모델을 적어 주면 도움이 됩니다.
3. 스크린샷을 찍으세요. 컴퓨터에서는 브라우저가 캡처할 창이나 탭을 물어봅니다. 휴대폰에서는 직접 찍고 나중에 첨부하세요.
4. "GitHub에서 열기"를 눌러 미리 채워진 이슈를 얻거나(무료 GitHub 계정 필요), "Discord용으로 복사"를 눌러 텍스트를 Discord에 붙여넣으세요.

버전, 화면 크기, 최근 오류가 보고서에 함께 담깁니다. 양식 자체에서는 아무것도 전송되지 않으며, 먼저 읽고 직접 보냅니다.

## 먼저 Molfar에게 물어보기

같은 양식의 "먼저 Molfar에게 물어보기" 블록은 설명을 GitHub 대신 Molfar에게 전달합니다. 새 채팅을 열고 기기 정보, 최근 오류, 앱 이름과 함께 텍스트를 보냅니다. 이 내용은 Molfar와 연결한 모델에게만 전달됩니다.

그는 원인을 찾아 내 앱 사본에서 수정을 시도하고, 당신은 이를 테스트합니다. 잘 작동하면 "작동합니다. 수정 보내기" 카드가 편집 가능한 양식을 열며, 거기서 제출할 때만 수정이 GitHub로 전달됩니다. 여전히 문제가 있으면 "여전히 문제 있음"이 그 내용을 Molfar에게 보냅니다. 원인이 Molfar Vertep 자체에 있으면 그는 고칠 수 없으며, 카드에 "GitHub에 신고하기"가 표시됩니다.
