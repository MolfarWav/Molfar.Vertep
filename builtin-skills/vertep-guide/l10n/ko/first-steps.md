# 첫 단계

아무것도 없는 상태에서 첫 채팅까지 가는 방법. 순서대로 한 번 읽어보세요.

## 1. 설치 및 시작

GitHub의 릴리스 페이지에서 사용 중인 시스템용 파일을 내려받아 압축을 풀고 시작하세요. Windows, macOS, Linux, Android, Docker가 지원됩니다. 릴리스 페이지에 어떤 파일을 받을지 나와 있습니다. 시작되면 브라우저에 일회성 설정 페이지가 열립니다. 열리지 않으면 Molfar Vertep이 시작된 창에 링크가 표시됩니다.

## 2. 계정 만들기

설정 페이지에서 첫 계정을 만드세요. 이 계정은 로컬에 있으며 컴퓨터를 벗어나지 않습니다. 이 첫 계정이 관리자이며 나중에 설정, 사용자에서 다른 사람을 추가할 수 있습니다. 사람마다 별도의 워크스페이스가 주어집니다.

## 3. 모델 연결

모델 없이는 아무것도 답하지 않으므로 시작 페이지 둘러보기가 여기서 시작됩니다. 설정(기어, 휴대폰에서는 오른쪽 위의 계정 메뉴)을 연 다음 "연결 및 모델", "연결 추가"를 차례로 엽니다. 제공자를 골라 API 키를 붙여넣으세요. 키를 붙여넣는 대신 로그인하려면 "구독(OAuth)"을, 컴퓨터에서 실행 중인 것을 쓰려면 "로컬 모델"을, OpenAI 호환 서버라면 "사용자 지정 엔드포인트"를 선택할 수도 있습니다.

연결에 키가 있으면 "연결됨"으로 표시됩니다. 이는 키가 저장되었다는 뜻일 뿐 모델이 작동한다는 뜻은 아닙니다. [[models]]를 참조하세요.

## 4. Roleplay 설치 및 열기

처음 시작하면 공식 앱이 Roleplay가 선택된 채로 표시되는 환영 화면이 나타납니다. "설치"를 누르면 처음 설치된 앱이 열립니다. 건너뛰었다면 시작 페이지에서 "스토어"를 열어 Roleplay를 설치하세요. 그런 다음 시작 페이지에서 클릭하고 "열기"를 누릅니다(휴대폰에서는 탭하면 열립니다).

## 5. 첫 채팅 시작

Roleplay 안에서 캐릭터를 고르고 채팅을 시작하세요. 카드, 페르소나, 채팅이 작동하는 방식은 Roleplay 가이드에 있습니다: [[roleplay:index]].

## Molfar에게 물어볼 곳

시작 페이지의 "Molfar" 줄에서 그의 탭을 여세요. "채팅 글자를 크게 해줘", "…라는 캐릭터를 만들어줘"처럼 앱에 관한 것은 무엇이든 물어보세요. 다음에 무엇을 해야 할지 모르겠다면 그것도 물어보세요. [[molfar]]를 참조하세요.
