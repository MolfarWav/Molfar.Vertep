# 모델 및 연결

Molfar와 앱이 답하려면 AI 모델이 필요합니다. 이 페이지에서는 모델을 연결하고, 표시할 모델을 고르고, 이미지와 음성을 설정하는 방법을 설명합니다. 모두 설정에 있습니다.

## 연결

연결은 제공자나 서버로 가는 저장된 링크입니다. 설정, "연결 및 모델", "연결 추가"를 여세요. 제공자 목록에서 다음을 선택할 수 있습니다:

- 잘 알려진 제공자: 하나를 골라 API 키를 붙여넣습니다.
- "구독(OAuth)": 키를 붙여넣는 대신 로그인합니다.
- "로컬 모델": 내 컴퓨터에서 실행되는 Ollama, LM Studio, llama.cpp 등.
- "사용자 지정 엔드포인트": OpenAI 호환 등 지원되는 형식 중 하나를 사용하는 모든 서버.

연결에 키가 있으면(또는 키가 필요 없으면) "연결됨"으로, 그렇지 않으면 "키 필요"로 표시됩니다. 모델이 작동하는지 테스트하는 것은 아닙니다. 키는 이 컴퓨터에만 저장됩니다.

## 표시할 모델 선택

하나의 연결이 수백 개의 모델을 가져올 수 있습니다. 연결 아래 목록에서:

- 선택기에 표시할 모델을 체크하세요. 아무것도 체크하지 않으면 모두 표시됩니다.
- 전환할 모델에 별표를 붙이세요. 이것이 "빠른 전환"이 되어 Molfar의 채팅과 앱에서 모델 선택기의 맨 앞에 옵니다.
- 슬라이더 아이콘으로 모델 자체 설정을 엽니다.

## 모델별 설정

모델 설정에는 컨텍스트 창, 최대 출력 토큰, 추론, 가격(백만 토큰당 달러), 프롬프트 캐시 확인, 페널티와 Min P 같은 샘플링 매개변수가 포함됩니다. "권장 설정"으로 적절한 값을 채울 수 있고, 되돌리기는 이전으로 돌아갑니다. Molfar, 앱의 채팅 답변, 개별 플러그인에 각각 별도의 블록을 적용할 수 있습니다. 비워 둔 필드는 전송되지 않습니다.

## 비전 모델

앱은 이 모델에 이미지를 보냅니다. 예를 들어 초상화로 캐릭터를 설명할 때입니다. "자동"은 이미지를 읽을 수 있는 가장 저렴한 모델을 사용합니다. 읽을 수 있는 모델이 없다면 그런 모델이 있는 연결을 추가하세요.

## 이미지

설정의 "이미지"에서는 모든 앱을 위한 이미지 생성을 설정합니다. 연결에서 이미지 모델을 추가하거나 이미지 서버를 추가할 수 있습니다: API를 켜고 시작한 ComfyUI, AUTOMATIC1111 또는 Forge 서버, 이미지 엔드포인트가 있는 모든 서비스. 별표를 붙인 이미지 모델은 즐겨찾기가 됩니다. Molfar는 각 모델의 용도에 따라 선택하며, Roleplay는 선택기에서 이들을 먼저 나열합니다.

## 음성

"음성"은 모든 앱에 텍스트 음성 변환을 제공합니다. 무료 Edge 음성은 바로 작동하며 각각 "테스트" 버튼이 있습니다. 음성 서비스(OpenAI, Groq 또는 로컬 서버)를 위해 모델 이름, 기본 음성, 키와 함께 "엔드포인트 추가"를 할 수도 있습니다.

## 비용 및 소형 모델

- Molfar는 큰 작업과 유료 이미지 전에 예상 비용을 보여줍니다. 설정, Molfar의 "비용 확인"을 참조하세요.
- 컨텍스트 창이 작은 모델은 Molfar의 전체 지침에 빠져들 수 있습니다. "소형 모델 모드"는 더 짧은 프롬프트를 보냅니다. 기본값인 자동은 32k 토큰 이하이거나 크기를 모를 때 켜집니다.

[[settings]]와 [[first-steps]]도 참조하세요.
