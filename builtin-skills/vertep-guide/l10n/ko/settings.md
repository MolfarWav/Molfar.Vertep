# 설정 지도

설정은 모든 앱이 공유하는 셸 자체의 대화 상자입니다. 상단 표시줄의 기어로 열거나, 휴대폰에서는 오른쪽 위의 계정 메뉴에서 엽니다. 이 페이지는 어디를 봐야 할지 알 수 있도록 각 섹션을 나열합니다.

## 섹션

- **일반.** 인터페이스 언어, "가이드" 블록(투어 끄기, 다시 재생, 새로운 기능 다시 표시), 계정: 사진, 이름, 비밀번호, "로그아웃".
- **백업.** 다른 컴퓨터로 이동하기 위해 전체 프로필을 내보내고 가져옵니다. [[devices]]를 참조하세요.
- **저장소.** 카드, 채팅, 스프라이트가 사용하는 이미지. "사용하지 않는 이미지 찾기"는 아무도 쓰지 않는 이미지를 찾아 휴지통으로 옮기고, "휴지통 비우기"는 확인 후 영구히 삭제합니다.
- **동기화.** Google Drive나 폴더로 기기 간 게임을 이동합니다. [[devices]]를 참조하세요.
- **연결 및 모델.** 제공자, 모델 목록, 즐겨찾기, 모델별 설정, 비전 모델. [[models]]를 참조하세요.
- **음성.** 텍스트 음성 변환: Edge 음성과 내 음성 엔드포인트.
- **이미지.** 이미지 생성: 이미지 모델과 이미지 서버.
- **Molfar.** 모든 앱에서 Molfar가 행동하는 방식:
  - 샌드박스에서의 인터넷 접근;
  - "긴 세션 자동 압축";
  - "소형 모델 모드";
  - "비용 확인": 자동, 항상 확인 또는 묻지 않음;
  - 그가 무언가 묻거나 끝내거나 실패할 때의 "알림";
  - "Molfar의 지침", 그를 위한 상시 선호 사항;
  - 보호된 파일 목록.
  [[molfar]]를 참조하세요.
- **메모리.** 앱이 채팅 전반에서 기억하고 찾는 방법입니다. 저렴한 임베딩 모델 하나로, 정확한 단어뿐 아니라 의미로도 찾을 수 있습니다. 선택 사항입니다. 기본적으로 Molfar Vertep이 모델을 직접 고릅니다: 먼저 당신의 컴퓨터에 있는 모델(LM Studio, Ollama, 키 필요 없음), 그다음 키가 있는 API 연결, 그다음 OpenRouter입니다. 아무것도 설정되지 않았으면 메모리가 그렇다고 알리고 단어로만 찾습니다. **이 컴퓨터에서 (선택 사항)**에서 **bge-m3**(권장, 우크라이나어, 러시아어, 영어에 가장 좋음) 또는 **EmbeddingGemma 2**(더 작음)를 고르고 **다운로드 후 연결**을 누르면, 모델을 클릭 한 번으로 당신의 컴퓨터에 내려받을 수도 있습니다. 엔진은 먼저 모델을 실행하는 프로그램을 설치하고(약 85 MB, 한 번만), 그다음 모델을 내려받아(587 MB 또는 346 MB) 연결합니다. 창을 닫아도 내려받기는 계속되며, 중단된 것은 멈춘 곳에서 이어집니다. 그 뒤로는 무료이고, 아무것도 인터넷으로 나가지 않으며, 모델은 작동하는 동안에만 메모리(약 1.1 GB 또는 0.6 GB)를 차지합니다. **삭제**는 디스크 공간을 돌려줍니다. Bun으로 엔진을 실행하는 컴퓨터가 필요하며, 휴대폰 런처로는 안 됩니다. 온라인 연결은 예비로 남고, 모델을 바꾸면 메모리가 벡터를 스스로 다시 만듭니다.
- **MCP 서버.** Molfar와 앱이 호출할 수 있는 도구 서버. 앱은 각각 꺼진 상태로 시작하여 필요한 것만 켭니다.
- **개발자.** 각 앱의 빌드 상태와 라이브 핫 리로드를 보여주며, 항상 켜져 있습니다.

## 관리자에게만 표시

- **서버.** Molfar Vertep이 이 컴퓨터에서 실행되는 방식: 포트, 시작 시 브라우저 열기, 네트워크의 다른 기기 허용(휴대폰용 QR 코드 포함), HTTPS, 앱의 패키지 다운로드 허용 여부, 버전과 업데이트 방법.
- **사용자.** 로그인할 수 있는 사람들. 각자 자신의 워크스페이스, 에이전트, 앱을 받습니다.

## 앱 설정

목록 맨 위의 **앱 설정** 그룹에는 자체 설정 페이지가 있는 설치된 앱이 나열됩니다(Roleplay는 거기서 “Vertep”으로 표시되며, Social도 포함). 하나를 누르면 설정이 닫히고 앱이 그 설정 페이지를 엽니다. Roleplay의 경우 채팅 모양, “Chat Behavior”(맞춤법 검사, 자동 수정), 스트리밍, 테마 및 나머지 채팅 설정입니다. 설정 페이지가 없는 앱은 목록에 나타나지 않습니다. 같은 페이지는 앱 안에도 있습니다: [[apps]]를 참조하세요.

> 휴대폰에서는 설정이 먼저 섹션 목록을 표시합니다. 하나를 눌러 들어가고 뒤로를 눌러 돌아옵니다.
