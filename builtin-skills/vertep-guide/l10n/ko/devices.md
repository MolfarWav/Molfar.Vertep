# 기기, 동기화 및 백업

휴대폰에서 Molfar Vertep을 사용하고, 기기 간에 이야기를 옮기고, 앱처럼 설치하고, 새 컴퓨터로 이동하는 방법.

## 휴대폰에서 열기

설정, 서버에서 "내 네트워크의 다른 기기 허용"을 켜면 같은 네트워크의 휴대폰이나 다른 컴퓨터에서 Molfar Vertep을 열 수 있습니다. QR 코드에 주소가 표시되므로 휴대폰 카메라로 스캔하세요. 모든 계정에는 여전히 비밀번호가 필요합니다. 휴대폰은 HTTPS에서만 마이크와 앱 설치를 허용하므로, 이를 사용하려면 같은 섹션에서 "HTTPS 사용"을 켭니다. 이 섹션들은 관리자에게 표시됩니다.

## 앱으로 설치

계정 메뉴의 "앱 설치"는 홈 화면이나 컴퓨터의 앱 목록에 Molfar Vertep을 추가합니다. 그런 다음 브라우저 표시줄 없이 자체 창에서 열립니다. iPhone에서는 Safari가 보관하는 위치(공유, 홈 화면에 추가)를 알려줍니다. http 주소로 컴퓨터를 여는 휴대폰은 먼저 https가 필요하며, 대화 상자가 방법을 설명합니다. 열려 있는 앱에는 "전체 화면"도 있는데, 이는 설치할 수 있는 자체 브라우저 탭에서 앱을 엽니다.

## 동기화

계정 메뉴의 "기기 동기화" 또는 설정, 동기화. 각 기기에서 Google로 한 번 로그인하세요. 플레이를 멈추면 "Push"를 누르고, 다른 기기에서는 "Pull"을 눌러 계속합니다. 처음 이후에는 변경된 내용만 이동합니다.

- 이동할 항목을 선택합니다: 앱과 그 데이터, Molfar의 채팅 및 프로젝트, 사진, 소리와 동영상, API 키와 MCP 설정. 키는 각 기기에서 입력하는 비밀번호 문구로 잠긴 경우에만 이동합니다.
- 양쪽 기기에서 같은 채팅이 변경되었다면 유지할 버전을 선택합니다. 다른 버전은 30일 동안 저장됩니다.
- 동기화된 폴더(Syncthing, 데스크톱용 Google Drive)나 USB 메모리를 위한 "폴더" 옵션도 있습니다.

## 백업

설정, 백업은 앱과 그 데이터, Molfar의 메모리와 채팅을 포함한 전체 프로필을 내보냅니다. "프로필 내보내기"를 누르세요. 비밀번호를 추가하면 API 키가 암호화되어 포함되며, 비밀번호가 없으면 백업에 키가 없으므로 다시 입력해야 합니다. 가져오기는 먼저 내용을 보여줍니다. "내 프로필 교체"를 누르면 현재 프로필이 먼저 저장된 후 교체됩니다.

새 컴퓨터로 한 번 이동할 때는 백업을 사용하세요. 자주 오가며 이동할 때는 동기화를 사용하세요.

## 앱 하나만

시작 페이지의 앱 세부 정보에는 "앱 내보내기"가 있어 해당 앱만의 백업 파일을 만듭니다. "앱 가져오기"는 이러한 파일을 가져옵니다. [[apps]]를 참조하세요.
