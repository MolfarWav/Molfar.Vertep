# Molfar Vertep-gids

Molfar Vertep is een programma dat op je eigen computer of telefoon draait en in je browser opent. Het host apps, waarvan **Roleplay** de belangrijkste is: lange chats met AI-personages. Je neemt het AI-model zelf mee (een API-sleutel, een abonnementsaanmelding of een model op je machine). Binnenin leeft **Molfar**, een ingebouwde agent die de apps voor je verandert wanneer je het in gewone woorden vraagt.

Je chats, personages en sleutels blijven in bestanden op je eigen schijf. Niets verlaat de machine behalve de aanroepen naar het model dat je hebt verbonden.

Deze gids is het overzicht: wat elk onderdeel is en hoe de onderdelen in elkaar passen. Elke app heeft ook zijn eigen Help voor zijn schermen.
